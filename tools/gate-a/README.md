# `tools/gate-a` — 관문 A 육안 판정 하니스

계측이 답하지 못하는 것을 눈으로 보기 위한 고정 표본이다.
**계측은 "폰트가 몇 픽셀로 그리는가"를, 육안은 "화면이 어떻게 보이는가"를 답한다**
([docs/FONT-A2.md](../../docs/FONT-A2.md) §6). 판정 기록은 [docs/GATE-A.md](../../docs/GATE-A.md) §1-4.

## 파일

| 파일 | 무엇 |
|---|---|
| `a2-visual.txt` | 표본 본문 — 폭 2배 · 표 그리기 · 기호 1칸 · 실사용 모양. **순수 텍스트** |
| `a2-visual.ps1` | 표본을 두 화면으로 출력. ESC가 필요한 절(굵게·밑줄·반전·색)은 여기서 낸다 |
| `a2-shell.cmd` | `EQMUX_SHELL`로 지정할 셸 래퍼. **ASCII 전용** |
| `evidence/` | 판정에 쓴 화면과 폭 계측 JSON (M2 · 2026-08-05) |

## 쓰는 법

```powershell
cd <repo>
npm run tauri -- build                      # 먼저. 낡은 빌드로 판정하면 안 된다 (아래 ⚠️)
$env:EQMUX_SHELL = "$PWD\tools\gate-a\a2-shell.cmd"
.\src-tauri\target\release\eqmux.exe
```

창을 **최대화**한다. 5초 뒤 1화면(폭·표·기호·실사용), 다시 12초 뒤 2화면(굵게·밑줄·반전·색)이 뜬다.
좁은 창에서는 윗부분이 스크롤로 밀려 **[1][2]를 못 본다** — 판정에서 제일 중요한 두 절이다.

**판정 기준**: `[1][2][3]`에서 끝 자리가 한 줄이라도 어긋나면 미달.
**겹침·잘림·틈**이 보이면 미달. 어느 것도 없으면 통과.

## ⚠️ 함정 셋 — 전부 한 번씩 밟았다

1. **낡은 빌드로 판정하지 말 것.** 경로를 옮긴 뒤 `target/`에 **동봉 이전 exe(3.22 MB)** 가 남아 있었다.
   그대로 열었으면 폴백 폰트를 보고 A-2를 판정할 뻔했다.
   → **exe 크기(동봉본 4.93 MB)** 와 `--font-probe`의 `resolvedBy: D2Coding`을 먼저 확인한다.
2. **텍스트 파일에 ANSI를 적지 말 것.** `ESC[1m`을 `.txt`에 적으면 화면에 `[1m`이 리터럴로 찍힌다 —
   **굵게를 재는 척만 하게 된다.** `Write-Host`도 안 된다(PowerShell이 ANSI를 삼킨다).
   `[Console]::Out.Write()`로 직접 쓴다.
3. **`.cmd`에 한글을 넣지 말 것.** cmd.exe는 `.cmd`를 OEM 코드페이지(949)로 읽는다.
   한글을 넣었더니 따옴표가 깨져 cmd가 주석 조각을 명령으로 실행했다. 한글은 `.ps1`에만 둔다.
