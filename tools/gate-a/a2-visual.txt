관문 A-2 육안 판정 표본 · 14px 고정 격자
증상은 "줄 밀림"이 아니라 겹침 · 잘림 · 틈이다 (FONT-A2.md §6).
※ 굵게·밑줄·반전은 이 파일이 아니라 a2-shell.cmd 가 낸다 — 텍스트 파일에는 ESC를 못 담는다.

[1] 폭 2배 — 한글이 ASCII 두 칸을 정확히 채우는가
ABCDEFGHIJKLMNOPQRST  <- 20칸
가나다라마바사아자차  <- 같은 자리에서 끝나야 한다
漢字漢字漢字漢字漢字  <- 〃
가A나B다C라D마E바F사G아H자I차J  <- 혼용. 앞뒤 간격이 고르게 보여야 한다

[2] 표 그리기 — 세로선이 위아래로 한 줄에 서는가
┌──────────┬──────────┐
│ 항목     │ 값       │
├──────────┼──────────┤
│ 한글     │ 2.0000   │
│ ASCII    │ 1.0000   │
│ 漢字     │ 2.0000   │
│ mixed 가 │ 0.000 px │
└──────────┴──────────┘

[3] 기호 1칸 — →·■ 가 한 칸을 넘지 않는가 (동봉이 지켜 주는 자리)
→→→→→→→→→→ <- 10칸
■■■■■■■■■■ <- 10칸
ABCDEFGHIJ <- 10칸 · 위 둘과 같은 자리에서 끝나야 한다
