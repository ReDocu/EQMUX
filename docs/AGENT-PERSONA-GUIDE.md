# 에이전트 페르소나 가이드 (학습용)

> **읽는 법**
> 이 문서는 각 에이전트를 캐릭터로 의인화해서 "누가 뭘 잘하는지" 감을 잡기 위한 학습 자료입니다.
> 페르소나는 **실제 리소스에 붙인 이름**일 뿐, 각자 다른 인격이 상주하는 것이 아닙니다.
> 건조한 목록 형태의 실체 정리는 [TEAM.md](./TEAM.md) 를 참고하세요.
>
> 각 항목은 **실체 / 강점 / 한계 / 부를 때** 4단으로 구성됩니다.
> 특히 **한계**를 먼저 익히면 잘못된 투입으로 낭비하는 일이 줄어듭니다.

---

## 🎯 리드 — "지휘관"

**실체**: 메인 세션 (Opus 5)

- **강점**: 유일하게 파일을 직접 쓰고 고칩니다. 대화 맥락 전체를 기억하고, 누굴 언제 투입할지 판단합니다. git, 셸, 편집 전부 담당.
- **한계**: 컨텍스트가 유한합니다. 파일을 수십 개 통째로 읽으면 그만큼 다른 걸 잊습니다 → 그래서 정찰을 따로 보냅니다.
- **부를 때**: 항상. 기본값입니다.

---

## 🔭 정찰병 — "스카우트"

**실체**: `Explore` 에이전트 (읽기 전용)

- **강점**: 넓게 훑는 데 특화. "이 기능 어디서 구현됐지?", "이 패턴 쓰는 파일 전부 찾아줘" 같은 걸 여러 디렉토리·네이밍 관습에 걸쳐 병렬로 뒤집니다. 파일 덤프가 아니라 **결론만** 들고 옵니다 — 지휘관 컨텍스트를 아낍니다.
- **한계**: 발췌만 읽습니다. **위치는 찾지만 코드 품질을 판단하진 못합니다.** 쓰기 권한 없음.
- **부를 때**: 코드베이스가 커진 뒤. 파일이 몇 개뿐인 초기 단계엔 무의미합니다.

---

## 📐 설계자 — "아키텍트"

**실체**: `Plan` 에이전트

- **강점**: 착수 전 전략 수립. 단계별 구현 순서, 손대야 할 핵심 파일 식별, "A안 vs B안" 트레이드오프 비교. 구조적 결정에 강합니다.
- **한계**: **파일을 못 씁니다.** 계획서만 반환합니다. 실행은 지휘관이 받아서 합니다.
- **부를 때**: 새 모듈 시작, 리팩터링 방향 결정, 스택 선택.

---

## 🔧 만능 기술자 — "해결사"

**실체**: `general-purpose` 에이전트 (전 툴 사용 가능)

- **강점**: 읽고 쓰고 실행까지 전부 됩니다. 긴 다단계 작업을 통째로 위임할 수 있는 유일한 에이전트. 여러 명을 동시에 띄워 각자 다른 모듈을 병렬 구현시킬 수 있습니다.
- **한계**: **독립 컨텍스트** — 우리 대화를 모릅니다. 브리핑을 부실하게 주면 엉뚱한 걸 만들어 옵니다. 지시서 품질 = 결과물 품질.
- **부를 때**: 서로 독립적인 작업 3개 이상이 동시에 있을 때.

---

## 📚 사서 — "가이드"

**실체**: `claude-code-guide` 에이전트

- **강점**: Claude Code 훅·슬래시커맨드·MCP 설정, Agent SDK, Claude API(모델 ID, 가격, 캐싱, 툴 사용) 전담. 이쪽은 기억으로 답하면 틀리기 쉬운데, 얘는 문서를 직접 봅니다.
- **한계**: 우리 프로젝트 코드는 모릅니다. 툴/API 질문 전용.
- **부를 때**: "훅 어떻게 걸지?", "이 모델 가격 얼마지?"

---

## 📋 기획자 — "PO"

**실체**: `pm-execution` 스킬 세트

- **강점**: 문서화 파이프라인 전부. PRD → 유저 스토리/잡 스토리 → 스프린트 계획 → 회고 → 릴리스 노트. OKR과 우선순위 프레임워크(RICE/ICE/Kano)도 포함. **템플릿이 정해져 있어서 결과물이 일정합니다.**
- **한계**: 코드를 안 봅니다. 문서 생산 전용.
- **부를 때**: 프로젝트 방향 정할 때 제일 먼저. 초기 단계에 가장 유용합니다.

---

## 🥊 저격수 — "레드팀"

**실체**: `strategy-red-team` + `pre-mortem` 스킬

- **강점**: **일부러 반대편에 섭니다.** 계획의 핵심 가정을 골라내서 공격하고, 실패 시나리오를 임팩트 × 확률 × 검증비용으로 순위 매긴 뒤 "이걸 제일 싸게 검증하는 법"을 돌려줍니다.
- **한계**: 비판만 합니다. 대안 구현은 안 합니다.
- **부를 때**: 큰 결정 직전. 스택 확정 전, 아키텍처 굳히기 전.

---

## 🛡️ 검사관 — "QA/보안"

**실체**: `/security-review`, `/review`, `test-scenarios` 스킬

- **강점**: 브랜치 변경분 보안 점검, PR 리뷰, 스펙에서 테스트 시나리오(해피패스 / 엣지케이스 / 에러처리) 생성.
- **한계**: 커밋된 변경분 기준으로 동작합니다. 코드가 있어야 일합니다.
- **부를 때**: PR 올리기 전, 배포 전.

---

## ✂️ 정리반 — "리팩터러"

**실체**: `/simplify` 스킬

- **강점**: 변경분에서 중복 제거, 재사용 가능한 부분 추출, 추상화 레벨 정리. **찾기만 하는 게 아니라 직접 고칩니다.**
- **한계**: **품질 전용 — 버그는 안 찾습니다.** 그건 검사관 담당.
- **부를 때**: 기능 완성 직후, 커밋 전.

---

## 🎨 디자이너 — "비주얼"

**실체**: `dataviz` + `artifact-design` + `pencil` MCP

- **강점**: 차트/대시보드 설계(접근성·라이트다크 대응 팔레트 포함), 공유 가능한 웹 페이지 산출물, `.pen` 디자인 파일 편집.
- **한계**: Artifact는 외부 리소스 로드 불가 — 전부 인라인이어야 합니다.
- **부를 때**: 데이터 시각화, 보고서, 링크로 공유할 문서.

---

## 🌐 조종사 — "브라우저"

**실체**: `claude-in-chrome` MCP

- **강점**: 실제 Chrome을 조작합니다. 클릭·폼입력·스크린샷은 물론 **콘솔 로그와 네트워크 요청을 읽습니다** → 웹 앱 디버깅에 강력. GIF 녹화로 플로우 기록도 가능.
- **한계**: JS `alert` / `confirm` 이 뜨면 세션이 멈춥니다. 사이트별 권한 필요.
- **부를 때**: 웹 UI 검증, 프론트 디버깅.

---

## 🎮 유니티 엔지니어

**실체**: `unity-mcp-skill`

- **강점**: Unity 에디터 직접 제어 — GameObject 생성/수정, 스크립트 편집, 씬 관리, 테스트 실행.
- **한계**: Unity 에디터가 켜져 있고 MCP가 연결돼 있어야 합니다.
- **부를 때**: 대상이 Unity 프로젝트일 때 주력.

---

## ⚔️ 대규모 작전 — "군단"

**실체**: `Workflow` 툴

- **강점**: 수십 개 에이전트를 스크립트로 조율합니다. 파이프라인, 적대적 교차검증(N명이 서로 반박), 판정단 투표, "더 안 나올 때까지 반복" 같은 패턴 구성 가능.
- **한계**: **토큰을 크게 씁니다.** 명시적 요청 있을 때만 돕니다 — "워크플로우로 돌려줘" / `ultracode`.
- **부를 때**: 전수 감사, 대규모 마이그레이션, 다각도 리뷰.

## 단계별 표준 편성

### Phase 0 — 빈 저장소 (현재 EQMUX)

```
📋 PO        →  PRD 초안 (무엇을 만드는지 확정)
🥊 레드팀     →  그 PRD 두들겨 보기
📐 아키텍트   →  스택·구조 설계
🎯 지휘관     →  스캐폴딩 직접 구현
```

> 정찰병 · 해결사 · 군단은 코드가 쌓인 뒤에나 의미가 있습니다. 이 시점에 부르면 낭비입니다.

### Phase 1 — 기능 개발

```
📐 아키텍트   →  구현 계획
🎯 지휘관     →  구현 (또는 🔧 해결사 병렬 투입)
✂️ 리팩터러   →  정리
🛡️ 검사관     →  리뷰
```

### Phase 2 — 규모 확대

```
🔭 스카우트   →  영향 범위 조사
🔧 해결사 ×N  →  모듈별 병렬 작업
🛡️ 검사관     →  통합 검증
⚔️ 군단       →  (요청 시) 전수 감사
```

## 투입 판단 체크리스트

새 작업을 받았을 때 순서대로 자문합니다.

1. **지휘관 혼자 5분 안에 끝나는가?** → 그렇다면 아무도 부르지 않습니다.
2. **뭘 만들지가 아직 안 정해졌는가?** → 📋 PO 먼저.
3. **되돌리기 어려운 결정인가?** → 📐 아키텍트 + 🥊 레드팀.
4. **어디를 고쳐야 할지 모르는가?** → 🔭 스카우트.
5. **서로 독립적인 작업이 3개 이상인가?** → 🔧 해결사 병렬.
6. **다 만들었는가?** → ✂️ 리팩터러 → 🛡️ 검사관.
