# EQMUX 0.6.3 릴리스 노트

2026-11-04 · 태그 `v0.6.3` · 변경 전체는 `CHANGELOG.md` [0.6.3]

## 다운로드

| 운영체제 | 파일 | 비고 |
|---|---|---|
| Windows 10·11 (x64) | `EQMUX_0.6.3_x64_portable.zip` | 압축을 풀어 `EQMUX\eqmux.exe` 실행 |

macOS 판은 나중에 따로 올립니다. 1.0 전에는 설치 파일을 내지 않습니다. 아직 코드 서명이 없습니다. Windows는 SmartScreen에서 [추가 정보] → [실행]을 누릅니다. 받은 파일은 릴리스에 붙은 `SHA256SUMS.txt`와 `Get-FileHash`로 대조할 수 있습니다.

## 고친 것

### Windows에서 셸 · 에이전트가 끝난 것을 알아차립니다

0.6.0부터 아는 한계로 적어 둔 문제입니다. 일부 Windows에서는 셸에서 `exit`를 치거나 에이전트가 스스로 끝나도 페인이 '기동 중' · '셸'로 남고, 실행 중 세션 수에도 들어갔습니다. 슬롯 목록 우클릭 [중지…]로만 정리됐습니다.

EQMUX는 터미널 출력이 끝나는 것(EOF)으로 종료를 알아챘습니다. 그런데 Windows의 의사 콘솔은 그 안의 프로세스가 끝나도 콘솔을 닫기 전에는 출력을 끝내지 않습니다. 이제 EQMUX가 셸 프로세스를 따로 지켜보다가, 끝나면 잠깐(0.2초) 남은 출력을 기다린 뒤 그 콘솔을 닫습니다. 그래서 종료 화면과 [▶ 셸 다시 열기]가 바로 뜹니다.

### 그 밖에

- 사람이 페인에 치던 줄 뒤에 대기 메시지가 붙어 함께 제출되던 문제. 이제 줄을 다 친 뒤에 넣습니다.
- 읽지 못한 `team.json`(끝 쉼표 · BOM 등)을 빈 팀으로 덮어쓰던 문제. 이제 덮지 않고 알립니다.
- 재개 · 재시작 직후 옛 프로세스의 종료가 새 세션에 '프로세스 종료'로 찍히던 문제.
- 등록 해제를 처리하는 사이 다시 누르면 다른 워크스페이스가 해제되던 문제.
- 편집기가 CRLF 파일을 LF로 바꿔 저장하던 문제.
- git: stash를 해시로 고르고, merge 커밋은 첫 부모와 비교합니다. git 메시지가 번역된 PC에서도 오류를 바르게 판정합니다.
- PowerShell에서 `eqmux` 출력을 파이프로 받으면 한글이 깨질 수 있던 문제.
- 임무 id로 `missions/` 밖 파일을 고치지 못하게 하고, 서버 명령 칸 · 진단 로그의 비밀값을 가립니다.

## 새로 생긴 것

- **워크스페이스 이름 바꾸기** — 탭 · 연결 화면 행 · 관제 카드를 더블클릭하거나 탭 메뉴 [이름 바꾸기…]. 경로를 다시 지정해도 사람이 정한 이름은 그대로 둡니다.
- **[▶ 셸 다시 열기]** — 끝난 슬롯 · 레일 · 페인 메뉴에서 같은 이름 · 자리 · 셸로 다시 엽니다.
- **창 자리 기억(Windows)** — 자리 · 크기 · 최대화를 기억합니다.
- 이름이 같은 탭에는 부모 폴더 이름을 덧붙이고, 툴팁에 경로를 보입니다. 좁은 창에서는 사이드 패널을 줄이고 터미널 그리드를 2열로 접습니다.

## 아는 한계

- 셸이 끝나는 순간 한꺼번에 많이 찍은 마지막 출력은 0.2초 안에 다 오지 않으면 잘릴 수 있습니다.
- 이름도 부모 폴더 이름도 같은 탭은 툴팁의 경로로 구분합니다.
