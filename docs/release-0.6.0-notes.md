# EQMUX 0.6.0 릴리스 노트

2026-11-03 · 태그 `v0.6.0` (`34c65d0`) · 변경 전체는 `CHANGELOG.md` [0.6.0]

## 다운로드

| 운영체제 | 파일 | 비고 |
|---|---|---|
| Windows 10·11 (x64) | `EQMUX_0.6.0_x64-setup.exe` | 설치 파일(현재 사용자) |
| Windows 10·11 (x64) | `EQMUX_0.6.0_x64_portable.zip` | 압축을 풀어 `eqmux.exe` 실행 |

macOS 판은 나중에 따로 올립니다. 아직 코드 서명이 없습니다. Windows는 SmartScreen에서 [추가 정보] → [실행]을 누릅니다.

## 팀을 지켜보는 앱에서, 팀과 같이 일하는 앱으로

0.6은 에이전트 세션을 띄워 두고 보는 데서 나아가, 승인 · 메시지 · 임무 · git을 앱 안에서 처리하게 합니다.

### 새 기능

- **승인함** — Claude Code의 도구 승인 요청에 대시보드에서 [허용] · [거부]로 답합니다.
- **메시지 버스** — 직함으로 보내기, `--re` 회신, `send --wait`, `eqmux read` · `eqmux list`, 긴급 에스컬레이션(`--severity high`).
- **임무** — 시작점 커밋과 그 뒤 커밋 수, 선행 임무, 임무별 비용, 임무 검토 화면([테스트 실행] · 시작점 기준 diff · [되돌려 보내기] · [승인]).
- **git 화면** — 브랜치 그래프 · blame · 덩어리 스테이징 · merge · rebase · cherry-pick · revert · stash · reset · 충돌 고르기. git 쓰기는 사람이 눌러야만 실행됩니다.
- **사이드 패널** — 코드 [git | 파일 | 문서], 확장 [MCP | 스킬 | 플러그인], 환경변수 편집, 저장 명령, 브라우저.
- **관제** — 동시 편집 경고, 담당 경로 밖 편집 알림, 멈춘 세션 배지, 자리 비운 사이 요약, 하루 비용 예산, 사용 한도 칩, 건너뛰기 팔레트(`Ctrl+Shift+K`).
- **역할 · 캐릭터** — 직무별 모델, 매 턴 상기, 캐릭터 기억, 초상 이미지.
- **처음 쓰는 사람** — 빠른 시작(두 세션), 첫 실행 고지, 과거 세션 검색과 재개.
- **트레이** — 창을 닫아도 세션은 트레이에서 계속 돕니다. 처음 숨길 때 앱 안에서 묻습니다.

### 안전

- 세션은 배정된 저장소 안만 다룹니다. 파일 도구가 저장소 밖 경로를 쓰면 훅이 거부합니다.
- 비밀값은 로그 패널 · `eqmux read` · diff에서 가려지고, 복사해도 클립보드 기록에 남지 않습니다.
- 메인 화면은 앱 밖 주소로 넘어가지 않습니다.

### 업데이트할 때

- 워크스페이스 등록 · 배치 · 설정 · 라이브러리는 그대로 남습니다. `session.db`는 `.bak`으로 옮기지 않고 그 자리에서 새 형식으로 고칩니다.
- 메시지 버스 이름이 바뀌었습니다. 업데이트한 뒤에는 앱을 한 번 다시 켜세요.

### 아는 한계

- 코드 서명이 없습니다(SignPath 신청 전).
- 일부 Windows(11 10.0.26300에서 확인)에서는 셸에서 `exit`를 치거나 에이전트가 스스로 끝나도 페인이 '실행 중'으로 남습니다. 슬롯 목록 우클릭 [중지…]로 정리됩니다. 0.6.1에서 고칩니다(B271).
- macOS는 0.6 QA를 Windows만큼 하지 못했습니다(B269 · 메뉴 막대 템플릿 아이콘).
- 실앱으로 확인하지 못한 동작이 있습니다 — Codex만 깔린 PC의 빠른 시작, 큰 저장소 clone 취소 등. 목록은 `docs/update-0.6-next-steps.md` §3.
