# 캐릭터 시트 가이드 — 고급 페르소나 만들기

고급 페르소나는 **캐릭터 시트가 전부**입니다. 판단 성향·말투·성격 입력칸 없이,
`personas/<id>.character.md` 시트 하나로 캐릭터를 정의합니다. 에이전트는 세션을 시작할 때
시트를 읽고 그 캐릭터로 응답합니다 — 실제 게임·역사·창작 인물 무엇이든 가능합니다.

---

## 1. 만드는 두 가지 방법

**새로 만들기** — 역할 라이브러리 → **+ 페르소나 추가** → **고급**. 페르소나와 함께 시트가
템플릿으로 생성되고 편집기가 바로 열립니다.

**기존 페르소나 승급** — 페르소나 선택 → 단계에서 **고급** → **캐릭터 시트 생성** → 저장.
기본·중급 프로필의 내용은 파일에 그대로 보존되므로, 단계를 되돌리면 이전 모습으로 돌아옵니다.

## 2. 핵심 규칙 — 간략하게만 채워도 된다

시트 머리말이 에이전트에게 "빈 항목은 원전 지식으로 자연스럽게 보완하라"고 지시합니다.
따라서 **최소 세 칸**만 채우면 캐릭터가 성립합니다:

| 칸 | 예 |
|---|---|
| frontmatter `name` | `세종대왕` |
| frontmatter `source` | `조선 역사 인물` |
| `## 정체성` (1줄) | `백성을 위해 문자를 만든 임금 — 온화하지만 집요한 탐구자` |

에이전트가 아는 인물이라면 말투·성격·화법을 알아서 구성합니다. 원하는 모습이 뚜렷할수록
아래 선택 섹션을 채우세요 — **대사 예시가 말투 재현에 가장 효과가 큽니다.**

## 3. 섹션별 작성법

```markdown
---
persona: kai            ← 소속 페르소나 id (자동 기입, 그대로 둠)
name: 세종대왕           ← 캐릭터 이름 (목록 카드에 표시됨)
source: 조선 역사 인물    ← 원전 — 게임·역사·창작 등 (카드에 함께 표시)
---
```

| 섹션 | 필수 | 요령 |
|---|---|---|
| 정체성 | ○ 1줄 | 캐릭터를 한 문장으로. 카드와 역할 파일의 정체성 줄이 된다 |
| 배경 | — 2~5줄 | 원전 배경 요약. 비우면 에이전트가 보완 |
| 성격 | — 3~5개 | 핵심 특성을 목록으로 |
| 말투 규칙 | — | 호칭 · 어미 · 자주 쓰는 표현 · 쓰지 않는 표현 |
| 대사 예시 | — 2~3개 | **가장 중요.** `상황 → 응답` 형식. 빌드 실패·리뷰 요청 같은 실제 업무 상황으로 |
| 판단 성향과의 연결 | — 1~3줄 | 캐릭터의 가치관이 업무 판단에 어떻게 드러나는지 |
| 경계 | 고정 | **수정 금지** — 아래 §4 |

작성 예 (대사 예시):

```markdown
## 대사 예시 (선택 · 2~3개 — 말투 재현에 가장 효과가 큼)
- 빌드 실패 보고 → "허어, 어디가 막혔는지 함께 살펴보시오."
- 완료 보고 → "수고하였소. 허나 시험은 거쳤는가? 근거를 먼저 보이시오."
```

권장 분량은 30~60줄입니다 (초과해도 차단하지 않음).

## 4. 경계 섹션 — 캐릭터가 업무를 해치지 않게

템플릿 끝의 고정 섹션은 안전핀입니다. 지우거나 고치지 마세요:

- 기술 정보·보고의 **정확성이 캐릭터 연기보다 우선**한다
- 캐릭터를 이유로 **금지·권한 규칙을 넘지 않는다**
- **코드·커밋 메시지·파일 산출물에는 캐릭터 말투를 쓰지 않는다** (대화만 캐릭터로)

## 5. 언제 어떻게 반영되나

- 역할 파일(`.eqmux/roles/<세션>.md`)에는 시트가 전재되지 않고 **정체성 1줄 + 시트 경로**만
  실립니다. 에이전트가 세션 시작 시 1회 읽으므로 매 턴 토큰 비용이 없습니다.
- 앱에서 **시트를 저장하면** 그 페르소나로 캐스팅된 살아있는 세션에 "다시 읽어라" 알림이
  자동으로 갑니다 — 대화 중에도 캐릭터를 고칠 수 있습니다.
- 고급 페르소나는 판단 성향·말투·성격을 따로 주입하지 않습니다 — 판단 기준까지 시트의
  "판단 성향과의 연결" 섹션이 담당합니다.

## 6. 관리

- **강등** — 단계를 중급/기본으로 내리면 시트 파일은 남고 적용만 꺼집니다. 다시 고급으로
  올리면 그대로 돌아옵니다.
- **시트 삭제** — 고급 폼의 "시트 삭제"가 파일을 지웁니다 (단계 설정은 유지 — 새로 생성 가능).
- **파일 직접 편집** — `%APPDATA%\com.eqment.eqmux\personas\<id>.character.md`. 앱 편집기와
  같은 파일이며, 앱에서 편집을 시작한 뒤 밖에서 바뀌면 저장이 거부됩니다(충돌 감지) —
  다시 열어 확인 후 저장하세요.
- 첫 설치에는 창작 캐릭터 예시(`luca.character.md` — 별지기 루카)가 번들됩니다.
  형식을 보고 원하는 인물로 바꿔 쓰세요.

## 7. 좋은 시트 체크리스트

- [ ] 정체성이 한 문장으로 캐릭터를 설명하는가
- [ ] 대사 예시가 실제 업무 상황(보고·리뷰·실패)으로 2개 이상 있는가
- [ ] 쓰지 않는 표현(금기 어투)을 적었는가 — 어긋난 말투를 막는 데 효과적
- [ ] 경계 섹션이 그대로 남아 있는가
- [ ] 60줄을 크게 넘지 않는가
