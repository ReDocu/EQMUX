AgentCommender — 기능별 디자인 스크린샷

실행 중인 앱을 기능별 화면 상태로 몰아 놓고 캡처한 27장. 목업이 아니라 실제 렌더 결과다.

1607 × 883 CSS · DPR 2 · 1.5× PNG · 팀 2 / 세션 4 (EQMux · Academy)

01 관제 대시보드

앱의 시작 화면. 스탯 타일 6종 · 팀 슬라이더 · 세션 셀 · 하단 요약 카드.

02 팀 편성 · 지휘

팀을 만들고, 팀원의 직책·관계를 정하고, 팀 전체에 명령을 내리는 흐름.

03 임무 (프로젝트)

임무를 등록하고 팀·세션에 배정하는 흐름. 배정하면 그 세션이 해당 폴더로 이동한다.

04 페르소나 (인격 데이터)

인격은 라이브러리에서 만들고 세션에 '심는다'. 원본 하나, 사본은 파생물.

05 터미널

탭(팀) · 분할 · 배치 프리셋 · 줌 · 검색. xterm.js 6 WebGL 렌더링.

06 사이드 패널

좌/우 배치 전환 · 너비 드래그. 앱을 떠나지 않고 git · 포트 · 로그 · 웹을 확인한다.

캡처: 실행 중인 앱을 Chrome DevTools Protocol로 각 기능 화면 상태로 만든 뒤 렌더러를 캡처했다. 브라우저 패널(27)만 네이티브 WebContentsView라 렌더러 캡처와 패널 캡처를 합성했다.
