## 1. 바뀐 전제 — 이게 제일 중요합니다

**EQMUX는 wmux 클론이 아닙니다. AgentCommender의 후속작입니다.**

오늘 오후에 팀장님이 확정하신 내용입니다.

| 항목 | 결정 |
|---|---|
| EQMUX 정체 | **AgentCommender를 Tauri로 재작성** |
| 스택 | Electron → **Tauri 2 + WebView2 + Rust** |
| AgentCommender | **기능 동결. 유지보수만.** (지금 우리 세션이 그 위에서 돕니다) |
| 자산 | **사양 계승 + 코드 참조** — 우리 코드니 클린룸 제약 없음 |
| wmux / cmux | **소스 열람 금지** — 라이선스 표기가 3중 불일치. 문서·동작만 참고 |
| 날짜 | 없음. **관문 통과로만** 진행 |

### 왜 재작성인가 — 실측값

| | AgentCommender | wmux 0.13.0 |
|---|---|---|
| 자체 코드 (dist) | **7.3 MB** | — |
| 런타임 (node_modules) | **432.5 MB** | — |
| 앱 데이터 | ~0 MB | 512 MB |
| 크래시 | **0건** | 10건 / 19일 |

> **우리가 쓴 코드는 7.3MB, 런타임이 432MB입니다.**
> 최적화 대상은 우리 코드가 아니라 런타임입니다. Tauri로 가면 배포물이 ~10MB가 됩니다.
>
> **재작성 명분은 "불안정해서"가 아니라 "무거워서"입니다.**
> AgentCommender는 wmux보다 이미 안정적입니다. 이 구분을 흐리면 안정성을 깎으면서 재작성하게 됩니다.
