## D. 알려진 버그·한계

1. **PowerShell 파이프 인코딩** — `eqmux … | Select-Object`에서 한글·—가 깨진다. 한국어 사용자가 매번 밟는다. CLI 출력 인코딩(UTF-8 BOM/콘솔 코드페이지) 한 곳만 보면 된다. **0.5.2 권장.**
2. P26 — `eqmux`와 다른 명령이 섞인 복합 명령은 여전히 승인을 묻는다.
3. B93 — 대기 브리프가 앱 메모리에만 있어 재시작 때 사라진다. 트레이(C)를 넣으면 체감이 줄어든다.
4. 메시지 상한(M3)으로 버려진 내 메시지가 `대기 중`으로 남는다.
5. O3(기록·로그 "더 보기" 상한), O4(큰 diff 가상화) — 프런트 RAM 후속.

## E. 이번 릴리스 때 같이 실기 확인

한국어 IME(B98), DE AltGr(B81), Codex 엔진 전환·미설치(B82·B85), 서버 탭 `npm run dev`(B77), OS 알림 토스트 클릭 → 페인(A2), 에이전트 4명 장시간 부하. 0.5.1에서 넣은 앱 데이터 소실 안전망은 옛 버전을 실행했는지 사용자 확인이 아직 남아 있다.
