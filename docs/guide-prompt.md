# 가이드 문서 작성 프롬프트

EQMUX 가이드 문서(`docs/*-guide.md`)를 새로 만들 때 아래 프롬프트를 복사해서 쓰세요.
`[ ]` 부분만 채우면 됩니다. 기존 가이드(persona-guide · character-guide)와 같은 톤·구조로 나옵니다.

## 프롬프트

```text
[주제]에 대한 사용자 가이드 문서를 docs/[파일명]-guide.md로 만들어줘.

대상 독자: [예: EQMUX를 처음 쓰는 사용자]
다뤄야 할 내용: [예: 개념 · 만드는 방법 · 파일 포맷 · 주의사항]

작성 규칙:
- 코드를 먼저 실측하고 쓸 것 — 화면 이름·버튼 문구·파일 경로·동작은 추측하지 말고
  실제 코드에서 확인한 것만 적는다
- 첫 문단에서 이 문서가 무엇을 알려주는지 한두 문장으로 정의한다
- 번호 섹션으로 나누고, 나열 가능한 사실은 표로, 파일 포맷·예시는 코드 블록으로 보여준다
- 실제 경로는 구체적으로 적는다 (예: %APPDATA%\com.eqment.eqmux\personas\)
- 규칙에는 근거를 함께 적는다 (예: 예산 5~10줄 (P3), 충돌 감지 (P-7))
- 마지막 섹션은 "자주 부딪히는 것" 또는 체크리스트로 끝낸다
- 한국어 · 존댓말 · 실무형 문장 — 마케팅 문구 없이
- 관련 가이드가 있으면 상대 링크로 연결한다 (예: [캐릭터 시트 가이드](character-guide.md))
- 완성 후 docs/에 저장하고 커밋 여부를 물어봐줘
```

## 사용 예

```text
임무(미션) 등록과 배정에 대한 사용자 가이드 문서를 docs/mission-guide.md로 만들어줘.

대상 독자: 팀 캐스팅까지 마친 사용자
다뤄야 할 내용: 임무 등록 · 세션 배정과 해제 · 역할 파일의 임무 블록 · 기본 임무 · 상태 변경

작성 규칙: (위와 동일)
```
