## 1. 범위 — 하는 것과 안 하는 것

**한다**

- 레이아웃 트리를 **실제 DOM으로 렌더**(중첩 분할 · 방향 · 비율)
- 잎마다 **xterm 인스턴스 + PTY 하나**를 붙인다 (`layout_attach_pty`로 id 기록)
- 분할(좌우/상하) · 닫기 — **4분할까지**
- 창 리사이즈 → 각 패널 `fit` → **`pty_resize` 전달**
- 닫을 때 **PTY·xterm·WebGL 컨텍스트 정리** (§2-1)

**안 한다 (다음 작업들이다)**

| 미루는 것 | 어디로 |
|---|---|
| 분할선 **드래그** 리사이즈 | `S2-3` — 이번엔 비율 고정(균등)이면 됩니다 |
| 방향 포커스 이동 단축키 · 패널 줌 | `S2-4` |
| 탭 · 워크스페이스 | `S2-5` · `S2-6` |
| 단축키 체계 전반 | `S2-7` — 이번 분할·닫기는 **버튼이나 임시 키**로 충분합니다 |
| design.pen 디자인 적용 | `S2-8` |

> **범위를 좁게 잡는 이유는 지난번과 같습니다.** `S2-2` 직후에 관문 A2가 옵니다.
> 드래그와 단축키까지 얹은 상태에서 A2가 미달하면 **어디가 먹는지 안 갈립니다.**

## 2. 설계 제약 — 관문 A2가 바로 뒤에 있습니다

이번 작업은 **처음으로 관문과 직접 만나는 구현**입니다. 아래 셋은 나중에 붙이는 최적화가 아니라
**처음부터 없으면 A2에서 원인을 못 찾는 항목**입니다.

### 2-1. 🔴 **닫으면 진짜로 없어져야 합니다** — A2가 여기서 갈립니다

A-4는 **유휴 RAM**을 잽니다. 닫은 패널의 PTY나 xterm이 살아 있으면 **그게 그대로 유휴 RAM입니다.**

```
layout_close(leaf_id) → Vec<String>   // 삭제된 잎 id들. 분할이 접히면 2개 이상 나올 수 있다
     ↓ 이 목록 전부에 대해
pty_kill(pty_id)  ·  xterm.dispose()  ·  WebGL 컨텍스트 해제
```

> **`layout_close`가 목록을 돌려주는 이유가 이겁니다.** 잎 하나를 닫아도 부모 분할이 접히면서
> 트리에서 사라지는 노드가 여럿일 수 있습니다. **반환값을 안 쓰고 닫은 잎만 정리하면 샙니다.**

**검증까지 이번 범위입니다** — 4분할 → 전부 닫기 → `pty_list`가 **비어 있는지** 확인.
`--appdata-report`처럼 무인으로 확인할 수 있으면 더 좋습니다(있는 플래그 재사용이면 충분).

### 2-2. 🔴 **WebGL 컨텍스트가 패널 수만큼 생깁니다** — A-3 회귀 위험

관문 A-3는 **터미널 1개**에서 통과한 값입니다(M2: 실작업 p99 1.6ms · 총지연 9.6ms).
패널이 4개면 **xterm + WebGL 애드온도 4개**입니다. 브라우저는 동시 WebGL 컨텍스트에 상한이 있고,
넘으면 **가장 오래된 컨텍스트를 조용히 잃습니다** — 그러면 캔버스 폴백으로 떨어지고 지연이 나빠집니다.

**요청**: 4분할 상태에서 **`--latency-probe`를 한 번 돌려 A-3 값을 확인**해 주십시오.
계측기는 이미 있고(`latency.ts` · 자가 검증 3항 통과) 판정선은 계측기가 기계에서 스스로 파생합니다.

> **미달해도 그 자체로는 실패가 아닙니다 — 값을 모르는 게 실패입니다.**
> 여기서 나빠지면 `S2-2` 범위에서 고칠지 별도 안건으로 뺄지는 제가 판단하겠습니다.
> `RENDERER-S1-3.md`가 *"WebGL2 하드웨어 경로"* 를 확인한 문서라, 거기가 깨지면 그 문서부터 갱신해야 합니다.

### 2-3. **폰트 스택은 패널마다 같아야 합니다** — A-2 회귀 방지

A-2(CJK 폭 2.0배)는 `FONT_STACK` 하나를 전제로 통과했습니다(동봉 D2Coding · 오차 0.000 px).
패널을 늘리면서 xterm 옵션을 **패널별로 따로 구성하면 스택이 갈릴 수 있습니다.**
**한 곳에서 만들어 나눠 쓰는 형태**로 유지해 주십시오.

### 2-4. 격리 스위치 유지

`S2-1`에서 확인하신 그것 그대로입니다 — 측정 모드에서 **라이브 `state.json`을 만들지도 않는다.**
A2 측정을 해원이 도니까 이게 깨지면 **측정이 제 상태 파일을 덮어씁니다.**

## 3. 관문 A2로 넘기는 조건 — 끝나면 제게 알려 주십시오

`S2-2` 완료 = **관문 A2 측정 착수 조건**입니다. 넘길 때 아래가 필요합니다.

| # | 무엇 | 왜 |
|---|---|---|
| 1 | **터미널 4개를 띄운 상태를 재현하는 방법** (수동 절차라도 됩니다) | 해원이 격리 인스턴스에서 같은 상태를 만들어야 합니다 |
| 2 | 4분할에서 **A-3 실측값** (§2-2) | 관문 A가 4패널에서도 서는지 |
| 3 | 닫기 후 **`pty_list` 비어 있음** 확인 (§2-1) | 새는 게 있으면 A2 숫자가 구현이 아니라 누수를 잽니다 |
| 4 | **빌드 크기** | 소스보다 낡은 빌드로 판정한 적이 한 번 있습니다 |

> **측정 창은 나눠 씁니다.** 해원의 A2 측정은 10분 남짓이고 그동안 **빌드·재시작을 못 합니다.**
> 준비되면 제게 먼저 말씀해 주십시오 — 제가 순서를 잡겠습니다.
