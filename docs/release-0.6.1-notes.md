## 고친 것

### 재시작 뒤 이전 세션 재생이 깨끗해졌습니다

앱을 다시 켜면 페인 위쪽에 이전 세션 기록이 다시 그려집니다. 지금까지는 Claude Code 같은 TUI가 제자리에서 고쳐 그리던 스피너 · 상태 줄(`Puzzling…`, `Sautéed for 1m 37s`)이 그릴 때마다 한 줄씩 저장되어, 재생 화면에 같은 줄이 겹치고 글자 조각이 서로 붙어 보였습니다.

이제 EQMUX가 세션마다 실제 터미널과 같은 크기의 가상 화면을 함께 돌리고, 화면 위로 밀려나 더는 바뀌지 않는 줄만 저장합니다. 그래서 재생은 그때 터미널에 보이던 모습 그대로입니다. 특정 CLI에 맞춘 처리가 아니라 셸 · 빌드 출력 등 모든 페인에 똑같이 적용됩니다.

- 창 크기를 바꿔도 줄이 두 번 저장되지 않고, 감싼 긴 줄은 한 줄로 저장됩니다.
- vim처럼 화면 전체를 쓰는 앱(대체 화면)은 저장하지 않습니다. Claude Code 전체 화면 모드의 대화는 트랜스크립트 패널에서 봅니다.
- **이미 저장된 잔해는 남아 있습니다.** 컨트롤 센터 → 저장 기록 초기화로 지울 수 있습니다.

### 열린 포트 목록이 다시 보입니다 (Windows)

일부 Windows 11 빌드에서는 세션이 연 개발 서버 포트가 목록에 나오지 않았습니다. `netstat`이 리스닝 상태를 잘못 보고했기 때문입니다. 이제 OS의 TCP 표를 직접 읽어 정확히 찾고, IPv6로만 연 포트도 보입니다.

## 바뀐 배포

- Windows는 포터블 zip 하나만 냅니다(0.6.0에 붙었던 `setup.exe`는 더 내지 않습니다).

## 아는 한계

- 앱이 비정상 종료되면 그 순간 화면에 떠 있던 줄(아직 밀려나지 않은 줄)은 재생에 남지 않습니다.
- Windows에서 창 폭을 줄일 때 터미널이 스스로 다시 감싸며 넘긴 줄 일부는 저장되지 않을 수 있습니다.
