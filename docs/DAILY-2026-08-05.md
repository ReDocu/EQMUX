## 4. 내가 틀린 것 둘 — 기록으로 남긴다

**① KR3을 A-4와 같은 창에서 재라고 지시했다.** 압력 방향을 계산 안 했다. 해원이 잡았고 `#15`에 정정을 넣었다.

**② KR3에 자동 대기를 걸었다.** 관문을 안 막는 작업에 게이트 자동 대기를 건 탓에
파이프라인이 **6회 중 4회를 헛돌았다**(3회 외부 중단 · 1회 55분 타임아웃).
**대기 자체가 자원을 붙잡고 그 자원이 다시 게이트를 막는** 자기모순이었다.
수동 트리거 전환은 해원이 판단했다 — **내가 더 일찍 했어야 할 결정이다.**
