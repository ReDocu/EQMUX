# 페르소나 추가 가이드

에이전트 세션에 개성을 입히는 **페르소나**를 만들고 관리하는 방법입니다.
(2026-08-15 · 단계별 독립 프로필 기준)

---

## 1. 페르소나란

EQMUX에서 세션의 역할은 두 축으로 나뉩니다 (P1 분리 원칙):

- **직무(job)** — 무엇을 하는가. 8종 고정(리드·기획·개발·디자인·QA·디버거·문서·릴리즈), 책임·금지·권한.
- **페르소나(persona)** — 어떻게 판단하고 말하는가. 이름·색 + 단계별 프로필.

하나의 페르소나를 여러 워크스페이스·직무에 재사용할 수 있습니다. 캐스팅(슬롯마다 직무 1 + 페르소나 1)이
되면 `.eqmux/roles/<세션>.md` 역할 파일로 합성되어 에이전트에 전달됩니다.

### 3단계 — 단계마다 완전히 독립된 프로필

| 단계 | 구성 | 주입되는 것 |
|---|---|---|
| **기본** | 판단 성향 | `## 판단 성향` |
| **중급** | 판단 성향 · 말투 · 성격 | `## 판단 성향` `## 말투` `## 성격` |
| **고급** | 캐릭터 시트만 | `## 캐릭터` (정체성 1줄 + 시트 포인터) |

핵심 규칙 세 가지:

1. **단계는 저장되는 설정입니다** — 편집창의 [기본 | 중급 | 고급] 버튼으로 고르고, 파일 frontmatter의
   `level:`에 기록됩니다. 목록 배지(중급=초록, 고급=호박)도 이 값을 보여줍니다.
2. **프로필은 단계마다 독립입니다** — 기본의 판단 성향과 중급의 판단 성향은 서로 다른 값입니다.
   단계를 전환하면 편집 폼의 값 전체가 그 단계의 프로필로 바뀌고, 서로 절대 섞이지 않습니다.
3. **활성 단계만 적용됩니다** — 나머지 단계의 내용은 파일에 보존되고, 강등해도 잃는 것이 없습니다.

## 2. 앱에서 추가하기 (권장)

1. 상단 앱바의 **역할** 버튼 → 역할 라이브러리 팝업.
2. **+ 페르소나 추가** → 단계 선택(**기본 / 중급 / 고급**) → 만들어진 페르소나의 편집 폼이 열립니다.
3. 폼을 채우고 **저장**. 단계는 편집창 맨 위의 단계 버튼으로 언제든 바꿀 수 있습니다 (저장 시 적용).
4. **삭제**는 편집창 맨 아래의 빨간 버튼 — 캐스팅 중인 페르소나는 잠깁니다.

### 단계별 작성 요령

**기본** — 판단 성향만 적습니다. 말투·성격 묘사가 아니라 **판단 우선순위 · 강조점 · 금기**
(FR-E-25), 권장 5~10줄 (P3 예산 — 초과 시 경고).

> 좋은 예: `전체 구조와 위험을 먼저 본다` · `증거 없는 완료를 인정하지 않는다`

**중급** — 판단 성향에 더해:
- **말투** — 프리셋 칩(간결한 존댓말 / 친근한 반말 / 차분한 설명형 / 건조한 보고체) 또는 자유 입력.
- **성격** — 행동 경향 1~3줄. 각 3줄 권장(초과 시 경고).

**고급** — 성향·말투·성격 입력칸이 사라지고 **캐릭터 시트가 전부**가 됩니다. 게임·역사·창작 인물의
간략한 정보만 채워도 에이전트가 원전 지식으로 보완해 그 캐릭터로 응답합니다.
작성법은 [캐릭터 시트 가이드](character-guide.md) 참고.

**색** — 직무 8색 팔레트에서 고릅니다 (점 안 글자 = 직무 앞글자). UI 표시 전용입니다.

## 3. 파일로 직접 추가하기

파일이 원본입니다 — 앱 화면은 파일을 따라갑니다 (FR-E-74).

| 계층 | 경로 |
|---|---|
| 전역 | `%APPDATA%\com.eqment.eqmux\personas\<id>.md` |
| 워크스페이스 오버라이드 | `<워크스페이스>\.eqmux\personas\<id>.md` (같은 id면 이쪽이 이김) |

캐릭터 시트는 같은 폴더의 `<id>.character.md`입니다. 오버라이드 항목은 앱에서 WS 배지가 붙고
편집이 잠기므로 파일을 직접 수정하세요.

### 파일 포맷 — 단계별 프로필 섹션

```markdown
---
id: kai
name: 카이
color: blue
level: mid
---

## 기본
### 판단 성향
전체 구조와 위험을 먼저 본다

## 중급
### 판단 성향
빠른 합의 · 작은 단위 검증
### 말투
간결한 존댓말 · 결론부터 말한다
### 성격
신중함 — 되돌릴 수 없는 결정을 늦춘다
```

- `level:` 이 활성 단계입니다 (`basic` / `mid` / `adv`). 없으면 내용으로 유추합니다.
- 프로필 섹션(`## 기본` 등)이 없는 구 파일은 본문 전체를 각 단계의 판단 성향으로 복사해 읽습니다.
- 고급은 텍스트 섹션이 없습니다 — `<id>.character.md` 시트가 전부입니다.
- 기본 섹션의 말투·성격은 무시됩니다 (기본 = 판단 성향만).

## 4. 언제 에이전트에 반영되나

| 시점 | 동작 |
|---|---|
| 캐스팅 · 세션 시작 | 역할 파일 합성 — 활성 단계의 프로필만 주입 |
| 앱에서 시트 저장 (고급) | 캐스팅된 살아있는 세션에 역할 파일 재합성 + "다시 읽어라" 알림 |
| 페르소나 편집 저장 | 다음 합성 시점(세션 시작·역할 저장)에 반영 |

## 5. 자주 부딪히는 것

- **"파일이 밖에서 바뀌었습니다"** — 편집 시작 후 파일이 외부에서 수정됨 (P-7 충돌 감지).
  목록이 새로고침되니 확인 후 다시 저장하세요. 시트도 같은 규칙입니다.
- **단계를 내렸는데 내용이 사라진 것처럼 보임** — 사라진 게 아니라 다른 단계의 프로필이 보이는
  것입니다. 단계 버튼을 다시 올리면 그대로 있습니다.
- **예산 경고** — 판단 성향 10줄 / 말투·성격 각 3줄 초과 시 경고만 하고 막지는 않습니다 (P3).
- **브라우저 dev 모드** — 실파일이 없으므로 캐릭터 시트(고급)는 Tauri 앱에서만 동작합니다.
