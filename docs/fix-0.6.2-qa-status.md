## 요약

0.6.2 코드 리뷰 라운드에서 찾은 54행을 고쳤습니다. 결과는 **수정 49 · 일부 5**(U189 · S28 · U186 · B295 · U182)이고, 안 한 행은 없습니다. 일곱 세션(eqmux-90 · b1 · 11 · 75 · ce · 32 · b7)이 파일 주인을 나눠 같은 작업 트리에서 고쳤고, 리드(eqmux-eb)가 B284와 정리를 맡았습니다. 원장 `제안·기대 동작` 칸 머리에 결과를 적었습니다(`[0.6.2 QA 수정 완료 — <세션>]` · `[0.6.2 QA 일부 수정 — <세션> · 남은 것: …]`).

S29(앱 잠금)는 이번 범위에서 뺐습니다. 사용자가 제안만 남기기로 골랐습니다.

앱을 띄워 확인한 것은 없습니다. 배포판 eqmux.exe 안에서 모든 세션이 돌고 있어 새 빌드를 띄울 수 없었습니다(아래 실기 확인 목록). 커밋하지 않았습니다.

## 실기 확인 목록

1. **B285** — Windows PowerShell 5.1 · pwsh 7에서 `eqmux who | Out-String`의 한글, `eqmux who` 화면 출력, `eqmux who > f.txt`(UTF-8), `eqmux send … | Select-String`의 종료 코드, stderr가 콘솔에 보이는지.
2. **B287 · B288** — 앱을 다시 켜고 역할 세션 [재개] · [대화 유지 재시작] → 빨간 '프로세스 종료'가 없고 슬롯이 종료 화면으로 튀지 않는지. 재개 직후 session.db의 그 세션 exit_code가 NULL인지.
3. **B275** — team.json에 끝 쉼표 · BOM → 열기 토스트, 세션을 만들면 '덮어쓰지 않습니다', 파일 바이트 그대로.
4. **B274** — busy 세션에 ask → 그 페인에 글을 치고 Enter 없이 기다림 → 턴이 끝나도 주입되지 않고, Enter 뒤 따로 들어가는지.

6. **B289 · B290** — 재지정 → 해제 → [되돌리기] 뒤 대화 · 스크롤백 · 재개 칩. 해제 → [폴더 찾기…]로 같은 폴더 재등록. 다른 항목 폴더로 재지정하면 오류 줄.
