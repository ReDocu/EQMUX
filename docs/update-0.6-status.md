# EQMUX 0.6 구현 현황

2026-11-02 · 리드 eqmux-68 · 범위는 `docs/update-0.6-scope.md`, 분담 · 진행 기록은 `docs/update-0.6-work-split.md`

## 요약

코드 작업은 사실상 끝났다. 범위 문서의 0.6 기능 묶음은 거의 다 들어갔고, 7개 스트림이 출시 전 실패 경로 점검까지 마쳤다. 남은 것은 세 가지다. 사람이 하는 실기 확인, 계정이 필요한 서명 · 업데이트, 출시 마무리(버전 · README · push)다.

| 검증 (HEAD `ad6f5f5`, 그 뒤는 CSS · 문구 · 문서만) | 결과 |
|---|---|
| `npx tsc --noEmit` | 오류 0 |
| `npm test` | 248개 통과 |
| `vite build` | 경고 0 (메인 청크 1,750 → 1,061 kB, 500 kB 안내만 남음) |
| `cargo clippy --lib` | 경고 0 |
| `cargo test --lib` | 238개 통과 · 1개 실패(`ports::…session_job` — 이 PC 환경 탓으로 원래부터 실패) |
| 커밋 | `sub_main`이 `origin/sub_main`보다 153커밋 앞. push는 아직 안 함 |
| 버전 | 아직 0.5.1 (`package.json`) |
