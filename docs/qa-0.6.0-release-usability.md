업데이트 경로와 앞 라운드 수정은 실앱에서 대부분 동작했습니다. 대신 **높음 1건(B271)** 이 새로 나왔습니다. 셸이나 에이전트가 스스로 끝나도 앱이 알아채지 못합니다.

## 먼저 고칠 것

1. **B271 — 자연 종료를 감지하지 못한다 (높음).**
   - 증상: 기본 터미널에서 `exit`, 역할 세션에서 Claude 신뢰 확인 'No, exit'. 두 경우 모두 프로세스는 끝났는데 페인은 '기동 중' · '셸'로 남습니다. 1분이 지나도 pty-exit · dead 이벤트가 없고, 실행 중 수(하단 · 트레이 · 닫기 확인창)에 계속 들어갑니다.
   - 원인: 종료 처리는 PTY 리더가 EOF를 받을 때만 돕니다(`src-tauri/src/lib.rs:643-730`). 이 PC(Windows 11 10.0.26300)에서는 클라이언트가 끝나도 ConPTY의 conhost가 남아 출력 파이프를 닫지 않습니다. 앱 자식으로 conhost만 남은 것을 프로세스 트리로 확인했습니다.
   - 우회: 슬롯 우클릭 [중지…]는 정상으로 정리됩니다('종료됨 · exit 0').
   - 제안: 자식 프로세스를 기다리는 스레드를 두고, 끝나면 의사 콘솔을 닫아 EOF를 만듭니다. 이전 Windows 빌드에서도 같은지 확인이 필요합니다.
2. **B272 — 등록 해제 연타로 다른 워크스페이스가 해제된다 (중간).** 처리 중 표시가 없는 1–2초 사이에 선택이 맨 위 행으로 옮겨 갑니다. 시험 중 실제로 일어났습니다.
3. **B273 — 언어를 바꾸면 기본 셸 칸이 다른 셸을 보인다 (낮음).** 표시만 틀리고 실제 값은 그대로입니다.
