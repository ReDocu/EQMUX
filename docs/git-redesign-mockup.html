2

저장소 선택 = 풀폭 드롭다운 — 지금의 정적 카드(gitp-repo)를 워크스페이스 전환 셀렉트로. 경로 전체 표시는 툴팁으로 이동.

3

브랜치+동기화+액션을 한 줄 툴바로 — 지금은 브랜치 카드 / 변경 요약 줄 / 큰 diff CTA가 3단으로 쌓여 있음. 이걸 [main▼] ↑0↓0 ··· [diff][↓pull][commit N][↑push N] 한 줄로 병합. 단, pull·push·commit 버튼은 현재 정책(G7 — "실행은 터미널에서")을 뒤집는 것이라 결정 필요. 모양만 갖추고 클릭 시 터미널로 안내하는 절충도 가능.

4

커밋 리스트 밀도화 — 행 높이 ~44px 고정, 메시지 왼쪽 · 작성자/시간/해시 오른쪽 정렬 한 줄, 연속 그래프 라인+도트, 아웃라인 스타일 ref 뱃지. 지금 refBadge()가 뱃지 1개만 뽑는데 레퍼런스처럼 origin/main·origin/HEAD 복수 표시로 변경.

5

워크트리 섹션은 EQMUX 고유 (레퍼런스에 없음) — 없애지 않고 한 줄 스트립으로 압축해 커밋 리스트 위에 유지.

커밋 기준 diff는 신규 기능 — 지금 diff는 HEAD↔워크트리 비교만 있음(B11 정책, 커밋 우클릭 메뉴에도 "워크트리 diff 열기"뿐). 커밋 행 클릭 시 부모 커밋 ↔ 이 커밋을 여는 모드를 백엔드(src-tauri/diff.rs)부터 새로 뚫어야 함. 이번 작업 중 가장 큰 덩어리.

7

파일 목록 → 디렉터리 트리 — 지금은 플랫 리스트+필터. 폴더 계층 들여쓰기 + A/M/D 상태 문자(색상)로 전환. 신규 파일(A) 선택 시 왼쪽 페인은 "(이 시점에는 파일이 없습니다 — 새 파일)" 빈 상태.

8

페인 헤더 색 구분 + 모달 표현 — 왼쪽(비교 대상)은 붉은 계열, 오른쪽(현재)은 초록 계열 헤더. 지금은 풀스크린 뷰인데 레퍼런스는 닫기 버튼이 있는 모달 — 풀스크린 유지 여부는 선택 사항(기존 나란히 비교·1:1 정렬·접기 엔진은 그대로 재사용).

#항목규모내용 · 대상
1헤더 타이틀바S · CSS 위주GitPanelTab.tsx 상단 + screens.css — 마크업 몇 줄과 스타일.
2저장소 드롭다운S정적 카드 → 워크스페이스 셀렉트. 상태 소스(scopeWorkspace)는 이미 있음.
3한 줄 툴바 병합M브랜치 카드·변경 요약·diff CTA 3단 → 툴바 1줄. 기존 브랜치 팝오버·2단 확인 로직은 재사용.
4pull / push / commit 버튼정책 결정G7("실행은 터미널에서") 반전 여부. UI만 두고 터미널 안내면 S, 실제 실행이면 백엔드 커맨드 포함 M+.
5커밋 리스트 밀도·뱃지 복수화S~MCSS 재작업 + refBadge() → 복수 refs 파싱. 데이터는 이미 refs에 다 있음.
6커밋 클릭 → 커밋 diffL · 신규 기능src-tauri/diff.rs에 부모↔커밋 diff 커맨드 추가 → backend/git.ts → GitDiffEditor에 비교 모드 파라미터. B11 정책 변경 포함.
7diff 파일 트리 + 페인 색 구분MGitDiffEditor.tsx 사이드바 트리화, 헤더 색, 새 파일 빈 상태. 비교 엔진은 그대로.
8워크트리 스트립 압축S기능 그대로, 표현만 한 줄로.
요약 — 8개 항목 중 6개는 레이아웃·밀도 재작업(CSS + 마크업 재배치)이라 기존 로직을 그대로 씁니다. 실제로 "기능"이 새로 생기는 건 ⑥ 커밋 기준 diff 하나이고(백엔드부터 필요, 가장 큼), ④ pull·push·commit 버튼은 코드보다 정책(G7) 결정이 먼저입니다. 이 두 가지만 방향을 정해 주시면 나머지는 바로 진행 가능한 범위입니다.
