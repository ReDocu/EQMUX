### PRD H — 도구 패널 (읽기 전용 실측)
- **git** — 활성 워크스페이스 스코프 · 10초 폴링. `git_overview`: 브랜치(분리 HEAD·빈 저장소 표시) · 업스트림 ahead/behind · `status --porcelain` 요약 · 최근 커밋 8건(+ref 뱃지)
- **포트** — `netstat -ano` 파싱 5초 폴링. 소유 pid를 세션 Job Object pid 목록과 대조해 세션/시스템 포트 분리, 프로세스명 실측, 충돌·외부 노출 집계
- **탐색기** — 실제 FS 트리(깊이 3·400개 상한, .git/node_modules 등 제외) + 텍스트 미리보기(64KB 상한·경로 탈출 거부). 임무 파일은 실측 임무 데이터로 구조화 표시
- **탐색기 파일 CRUD (M24 — 사용자 확정으로 읽기 전용 원칙 개정)** — 파일·폴더 생성 / 이름 변경(같은 부모 안에서만) / 삭제(**휴지통으로**, 영구 삭제·폴백 없음, 2단 확인) / 원문 편집 저장(전문 읽기 1MB 상한 — 64KB 잘린 미리보기를 저장하는 사고 차단, 원자적 쓰기). 모든 쓰기는 읽기와 같은 경로 탈출 가드 + **.git 불가침**. 임무 파일 변경은 임무 목록 재실측으로 이어진다 (FR-E-74)
- **에디터 고도화 (M27)** — **Ctrl+S 저장** · **외부 변경 충돌 감지**(mtime 대조 — 편집 중 에이전트가 같은 파일을 바꾸면 저장 거부, 마지막 저장 승리 방지) · **미저장 이탈 보호**(다른 파일 클릭 1회 경고 후 재클릭 확인, ESC 팝업 닫기 차단)
- **로그** — event 테이블 실스트림 (M3)
- **diff 뷰어** — 변경 파일 목록(porcelain+numstat) + HEAD↔워크트리 나란히 비교(`git diff -U999999` 양측 재구성). 신규=전부 add · 삭제=전부 del · 바이너리=사유 표시 · 3,000줄 상한
- **브라우저** — 세션 포트 미리보기 (M17). 실측 포트 칩(netstat + Job Object 귀속 공유) + 주소 입력 → iframe 렌더 + 새로고침. **대상은 localhost·127.0.0.1로 제한** — 임의 웹 브라우징은 사용자의 브라우저 몫 (관측 지향 원칙)
- **진입점 개편 (M25)** — 사이드 패널 탭은 대화·git·포트·로그·브라우저 5종. **임무·파일 탐색기는 전체 화면 팝업으로 승격** (앱 바 `임무` 버튼 · ESC 닫기 · 터미널 전체 화면 위에도 뜸 · 트리 320px). **대화 버튼도 앱 바 전역 도구** — 터미널 전체 화면에서 사이드 패널이 합류해 열린다
- **git 패널 워크트리·체크아웃 (M36 — 사용자 확정으로 안전 범위 개방)** — orca식 기능 중 **커밋 이력을 바꾸지 않는 작업 트리 조작만**: ①브랜치 목록(로컬 + 원격 전용 이름, DWIM 추적 브랜치) → 클릭 체크아웃(2단 확인, FR-E-52 패턴 — 공유 repo 고지) + 새 브랜치 생성·전환 ②워크트리 목록(`git worktree list --porcelain` 실측 — 외부 생성도 잡힘, MAIN/세션/외부 뱃지) ③이름 있는 워크트리 생성(base ref 분기 — `worktree_create(name, base)`, 세션 워크트리와 같은 `.eqmux/worktrees/` 규약) ④워크트리에서 기본 터미널 열기(그 cwd로 셸 — 역할 부여는 세션 상세에서). **워크트리 삭제는 두지 않는다** (FR-E-64 — 머지·정리는 사람 몫)
- **git 이력 조작·프로세스 조작은 여전히 없다** (pull·push·commit·스테이지·프로세스 kill) — 실행은 터미널 페인에서 사람이 한다 (G7과 같은 원칙). 파일 편집은 M24, 워크트리·체크아웃은 M36에서 사용자 확정으로 개방
- 유닛 테스트: git 임시 저장소 왕복 · netstat 파싱 · 트리 제외/경로 탈출 가드 · diff 양측 재구성(M/A/D)
