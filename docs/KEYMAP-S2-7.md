## 0. 한 장

**키가 갈리는 자리에서는 AgentCommender를 따른다. wmux가 아니다.**

관문 B(도그푸딩)의 판정은 *"아무도 옛 앱으로 돌아가지 않는다"* 다. 돌아가게 만드는 가장 싼 방법이
**손이 기억하는 키를 바꾸는 것**이다. wmux 호환은 아무도 원한 적 없다 — 우리 팀은 wmux를 안 쓴다.

| 지금 확정이 필요한 것 | 결정 |
|---|---|
| `S2-4` 줌 키 — WORKPLAN(`Ctrl+Shift+Enter` · wmux 키) vs 실측(`Ctrl+Shift+Z`) | **`Ctrl+Shift+Z`** (계승) — WORKPLAN 정정 |
| `S2-4` 방향 포커스 | **`Ctrl+Alt+↑↓←→`** (신규 — AgentCommender에 없던 기능) |

## 1. 원칙 넷 — 표보다 이게 정본이다. 표에 없는 키는 이걸로 정한다

### ① 층 규칙 — 수식키가 소유자를 가른다

| 층 | 소유 | 뜻 |
|---|---|---|
| `Ctrl+Shift+*` | **앱** | 분할·닫기·줌·워크스페이스 — 앱 전역 동작 |
| `Ctrl+Alt+*` | **앱 (내비게이션)** | 포커스 이동·탭 조작. AgentCommender가 `!e.altKey`로 Alt 층을 통째로 비워 놨다 — **충돌 없는 빈 땅**이다 |
| `Alt+숫자` / `Ctrl+숫자` | **앱 (직행)** | 탭/워크스페이스 바로 가기 |
| `Ctrl+*` 단독 · 나머지 전부 | **터미널** | 셸에 통과시킨다. 앱이 가로채지 않는다 |

### ② 예외는 Windows Terminal 관행만 — 그리고 전부 계승이다

`Ctrl+C`(선택 시 복사)·`Ctrl+V`·`Ctrl+F`·`Ctrl+=`/`-`/`0`·`Ctrl+Tab`.
①을 어기는 키들이지만 **AgentCommender가 이미 이 키로 팀을 길들였다.** 원칙보다 손가락이 세다.

- `Ctrl+C`는 **선택이 있을 때만 복사**, 없으면 SIGINT — Windows Terminal 방식 그대로 (`S3-1`)
- `Ctrl+F`·`Ctrl+V`는 bash/WSL readline과 충돌한다(`forward-char`·`quoted-insert`).
  내부 팀은 PowerShell이라 실충돌이 낮다 — **감수하고, ④로 도망길을 연다**

### ③ 마우스 없이 전 기능 도달 — DoD는 키가 아니라 팔레트가 지킨다

단축키를 다 못 외운다. **명령 팔레트(`Ctrl+Shift+P` · 신규)가 전 명령의 이름 검색 진입점**이고,
S2-7의 완료 기준 "마우스 없이 전 기능 도달"은 **팔레트 포함**으로 판정한다.
단축키가 없는 기능이 있어도 되지만, **팔레트에 없는 기능은 있으면 안 된다.**

### ④ 전 바인딩은 `config.toml`에서 재정의·해제 가능 (B19 · `S3-5` 연동)

하드코딩 `switch`문(AgentCommender 방식)을 반복하지 않는다. **기본값 테이블 하나가 코드와 문서의
공동 원천**이고, `config.toml`의 `[keys]` 절이 그걸 덮어쓴다. GUI는 안 만든다(B19 축소 확정).

## 2. 기본값 표

출처 표기: **계승** = AgentCommender 실측 그대로 · **신규** = 양쪽에 없음 · **변경** = 실측과 다르게 감(사유 필수)

### 패널 (S2-2·S2-3·S2-4)

| 동작 | 키 | 출처 |
|---|---|---|
| 좌우 분할 | `Ctrl+Shift+D` | 계승 (wmux `Ctrl+D`는 셸 EOF와 충돌 — 안 따른다) |
| 상하 분할 | `Ctrl+Shift+E` | 계승 |
| 패널 닫기 | `Ctrl+Shift+W` | 계승 |
| **방향 포커스 이동** | **`Ctrl+Alt+↑↓←→`** | **신규** — AgentCommender는 마우스 클릭뿐이었다 (`S2-4`) |
| **패널 줌** | **`Ctrl+Shift+Z`** | **계승** — wmux `Ctrl+Shift+Enter` 아님. **WORKPLAN 정정 대상** (`S2-4`) |

### 탭 · 워크스페이스 (S2-5·S2-6)

AgentCommender는 팀(=워크스페이스) 한 층뿐이었다. EQMUX는 **워크스페이스 > 패널 > 탭** 세 층이라
키가 새로 필요하다 — 계승할 관례가 없는 자리는 wmux 관행을 빌린다.

| 동작 | 키 | 출처 |
|---|---|---|
| 워크스페이스 생성 | `Ctrl+Shift+T` | 계승 (팀 추가가 이 키였다) |
| 워크스페이스 순환 | `Ctrl+Tab` / `Ctrl+Shift+Tab` | 계승 (팀 전환이 이 키였다) |
| 워크스페이스 직행 | `Ctrl+1~8` | 신규 (wmux 관행) |
| 워크스페이스 이름변경 | `Ctrl+Shift+R` | 신규 (wmux 관행) |
| 새 탭 | `Ctrl+Alt+T` | 신규 — `Ctrl+T`는 터미널 층(①)이라 안 쓴다 |
| 탭 순환 | `Ctrl+Alt+[` / `]` | 신규 |
| 탭 직행 | `Alt+1~8` | 신규 (wmux 관행) ⚠️ bash `Meta+숫자`와 충돌 — ④로 해제 가능 |
| 탭 닫기 | `Ctrl+Alt+W` | 신규 — AgentCommender는 단축키 없이 ×/휠클릭뿐이었다 |
| 사이드바 토글 | `Ctrl+Shift+B` | **변경** — AgentCommender에선 브라우저 패널 토글. EQMUX는 내장 브라우저가 없어 **키가 비었고, "보조 패널 토글"이라는 몸짓이 같다.** wmux `Ctrl+B`는 bash `backward-char`와 충돌이라 안 따른다 |
| 명령 팔레트 | `Ctrl+Shift+P` | 신규 (VS Code·wmux 관행) — 원칙 ③의 기둥 |

### 터미널 (S3-1·S3-2·S3-3)

| 동작 | 키 | 출처 |
|---|---|---|
| 복사 / 붙여넣기 | `Ctrl+C`(선택 시) / `Ctrl+V` + 우클릭 | 계승 — `Ctrl+Shift+C/V`(wmux) 아님 |
| 검색 | `Ctrl+F` (Enter/Shift+Enter/Esc) | 계승 |
| 폰트 크기 | `Ctrl+=` / `Ctrl+-` / `Ctrl+0` (8~24 클램프) | 계승 |
| 전체화면 | `F11` | wmux 관행 (P2 — 급하지 않음) |

### 예약 — 지금 배정하지 않는다

`Ctrl+Shift+L`(배치 프리셋 — AgentCommender에 있었으나 EQMUX 1차 범위 밖) ·
`Ctrl+Shift+U`·`Ctrl+Alt+N`(알림 — G9 · P2) · `Ctrl+,`(설정 — H7). **비워 둔 게 결정이다** — 선점 금지.

## 3. 미결 — S2-7 구현 전까지 닫는다

| # | 무엇 | 왜 지금 안 정하나 |
|---|---|---|
| 1 | `Ctrl+Tab`이 워크스페이스 순환인가 **탭 순환**인가 | 세 층이 실제로 돌아야 손맛을 안다. `S2-5`(탭) 인수 후 도그푸딩 하루 써 보고 확정 |
| 2 | `Alt+1~8` 직행의 대상 (탭 vs 워크스페이스) | 1번과 같은 판단이다 — 같이 닫는다 |
| 3 | WSL/bash 사용자용 **Alt 층 일괄 해제 프리셋** | ④의 바인딩 파일 형태가 `S3-5`에서 정해진 뒤 |
