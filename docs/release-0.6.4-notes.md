# EQMUX 0.6.4 릴리스 노트

2026-11-20 · 태그 `v0.6.4` · 변경 전체는 `CHANGELOG.md` [0.6.4]

## 다운로드

| 운영체제 | 파일 | 비고 |
|---|---|---|
| Windows 10·11 (x64) | `EQMUX_0.6.4_x64_portable.zip` | 압축을 풀어 `EQMUX\eqmux.exe` 실행 |
| macOS 11 이상 (Intel·Apple Silicon) | `EQMUX_0.6.4_universal.dmg` | 처음 열 때 [처음 열기](#처음-열기) 절차가 한 번 필요합니다 |

1.0 전에는 설치 파일을 내지 않습니다. 아직 코드 서명이 없습니다. Windows는 SmartScreen에서 [추가 정보] → [실행]을 누릅니다. macOS는 아래 'macOS에서 쓰기'를 따릅니다. 받은 파일은 릴리스에 붙은 `SHA256SUMS.txt`와 대조할 수 있습니다(Windows `Get-FileHash`, macOS `shasum -a 256`).

## 고친 것

### macOS 터미널에 한글이 그대로 들어갑니다

0.6.3 macOS 판까지는 터미널 페인에 한글을 치면 음절마다 첫 자모만 들어갔습니다. '한글'을 치면 셸에는 'ㅎㄱ'이, '하나'를 치면 'ㅎ나'가 갔습니다. 셸, Claude Code 입력란, vim이 모두 같았습니다. 세션 이름이나 대화 입력란 같은 입력칸은 정상이었습니다.

macOS 한글 입력기는 조합 중인 글자를 앞 글자와 바꿔 끼우는 방식으로 보냅니다(ㅎ → 하 → 한). EQMUX의 터미널은 첫 자모만 받고 바꿔 끼우기를 버렸습니다. 이제 바꿔 끼울 때마다 앞 글자를 지우고 새 글자를 보냅니다.

셸 스크립트의 `read`나 파이썬 `input()`처럼 줄 단위로 받는 곳에서도 한글이 깨지지 않도록, 터미널을 UTF-8 지우기(`iutf8`)로 엽니다. Terminal.app이나 iTerm2와 같은 설정입니다.

### 그 밖에

- 서버 버튼 이름 · 환경변수 편집 · 새 스킬 이름 칸에서 한글 마지막 글자를 조합하는 중에 Enter를 누르면, 조합이 끝나기 전에 저장될 수 있던 문제. Git 이름 창과 과거 세션 검색도 같은 판정을 씁니다.
- 오래된 macOS(Safari 16.4 미만인 macOS 11·12, 13.0–13.2)에서 앱이 빈 창으로 뜨던 문제. 0.6.3 macOS 판에서 먼저 고친 것을 이번 판에 합쳤습니다.

## 바뀐 것

- 앱 아이콘을 새 그림으로 바꿨습니다.

## macOS에서 쓰기

[EQMUX 0.6.3 for macOS](https://github.com/ReDocu/EQMUX/releases/tag/v0.6.3-macos) 다음 macOS 배포입니다. 이번부터 Windows 판과 같은 릴리스에 함께 올립니다. 위에서 고친 것을 모두 포함합니다.

### 설치

1. `EQMUX_0.6.4_universal.dmg`를 받습니다. 하나의 파일로 Intel 맥과 Apple Silicon 맥을 모두 지원하고, macOS 11 이상이 필요합니다.
2. dmg를 열고 EQMUX를 응용 프로그램 폴더로 끌어 놓습니다. 0.6.3을 쓰고 있었다면 덮어씁니다. 세션과 설정은 그대로 남습니다.
3. **처음 열 때 한 번** — 아래 [처음 열기](#처음-열기) 절차를 따릅니다.
4. Claude Code가 없다면 앱이 알려 주는 명령으로 설치합니다.
   ```
   curl -fsSL https://claude.ai/install.sh | bash
   ```

받은 파일은 릴리스에 붙은 `SHA256SUMS.txt`와 대조할 수 있습니다.

```
shasum -a 256 ~/Downloads/EQMUX_0.6.4_universal.dmg
```

### 처음 열기

EQMUX는 Apple 공증(notarization)을 받지 않은 앱입니다. 서명은 ad-hoc입니다. 그래서 인터넷에서 받은 EQMUX를 처음 열면, macOS가 Gatekeeper로 실행을 막습니다. 앱이 고장 난 것은 아닙니다. 아래 절차는 처음 한 번만 하면 되고, 그다음부터는 그냥 열립니다.

#### macOS 15 Sequoia 이상

macOS 15부터는 예전처럼 Control-클릭(우클릭) › [열기]로 넘어갈 수 없습니다. 시스템 설정에서 허용해야 합니다.

1. 응용 프로그램 폴더의 EQMUX를 더블클릭합니다.
2. **'"EQMUX" 열지 않음'** 창이 뜹니다. 여기서 **[완료]**를 누릅니다.
   - **[휴지통으로 이동]은 누르지 마세요.** 앱이 휴지통으로 갑니다. 이미 눌렀다면 휴지통에서 응용 프로그램 폴더로 다시 옮기세요.
3. **Apple 메뉴  › 시스템 설정 › 개인정보 보호 및 보안**을 엽니다.
4. 오른쪽을 맨 아래 **보안** 항목까지 내립니다. **'"EQMUX"이(가) Mac을 보호하기 위해 차단되었습니다.'** 옆의 **[그래도 열기]**를 누릅니다.
   - 이 문구는 1번에서 한 번 열기를 시도한 뒤 약 1시간 동안만 보입니다. 보이지 않으면 1번부터 다시 하세요.
5. 암호(또는 Touch ID)를 넣습니다.
6. 확인 창이 한 번 더 뜨면 **[그래도 열기]**를 누릅니다. EQMUX가 열립니다.

#### macOS 11–14

1. 응용 프로그램 폴더에서 EQMUX를 **Control-클릭(또는 우클릭) › [열기]**를 고릅니다.
2. '확인되지 않은 개발자가 배포했기 때문에…' 창이 뜨면 **[열기]**를 누릅니다.

이 방법이 안 되면 위 macOS 15 절차의 3–6번(시스템 설정 › 개인정보 보호 및 보안 › [그래도 열기])을 따릅니다.

#### 터미널로 한 번에 (모든 버전)

받은 파일에 붙은 격리 표시를 지우면, 확인 창 없이 바로 열립니다.

```
xattr -dr com.apple.quarantine /Applications/EQMUX.app
```

앱을 응용 프로그램 폴더가 아닌 곳에 두었다면 경로를 바꿔 주세요.

#### 다른 문구가 뜰 때

- **'"EQMUX"이(가) 손상되었기 때문에 열 수 없습니다'**: 다운로드가 깨졌을 수 있습니다. dmg를 다시 받아 위의 체크섬을 확인한 뒤 다시 설치하세요. 그래도 같으면 위의 `xattr` 명령을 실행합니다.
- **dmg에서 바로 실행했을 때 열리지 않거나 저장이 안 될 때**: EQMUX를 응용 프로그램 폴더로 옮긴 뒤 여세요.

### 알려진 한계

- **서명은 ad-hoc이고 공증을 받지 않았습니다.** 그래서 처음 열 때 [처음 열기](#처음-열기) 과정이 필요합니다.
- **입력칸이 따옴표와 대시를 바꿔 적습니다.** macOS의 텍스트 자동 고침 때문입니다. 임무 목표나 git 커밋 메시지에 친 `"`와 `--`가 둥근 따옴표와 긴 대시(`“ ” —`)로 바뀌고, 첫 글자가 대문자가 될 수 있습니다. 시스템 설정 › 키보드 › 텍스트 입력의 [편집…]에서 자동 대문자와 스마트 따옴표·대시를 끄면 피할 수 있습니다. 이 설정은 다른 앱에도 적용됩니다.
- **터미널에서 ⌘A(전체 선택)가 동작하지 않습니다.** 메뉴 막대는 아직 기본 메뉴라 설정(⌘,)이 없습니다. 폴더 선택 창은 영어로 뜹니다.
- **다시 켜면 화면이 일부만 돌아옵니다.**
  - Claude Code 페인의 이전 화면은 재생되지 않습니다. 지난 대화는 트랜스크립트 패널이나 페인에 뜨는 `claude --resume` 안내로 이어 가세요.
  - 기본 터미널은 다시 열리지 않습니다. [▶ 셸 다시 열기]로 엽니다.
- **역할 세션을 띄울 때 이벤트 피드에 '사용자 요청으로 종료'가 한 번 찍힐 수 있습니다.** 실제로 끈 것이 아니고, 세션은 그대로 뜹니다.
- **창을 Dock으로 오래 숨겨 둔 뒤 종료하면, 확인 없이 세션이 정리될 수 있습니다.** 코드로만 찾은 위험이고 확인 중입니다. 종료 전에 창을 한 번 열어 두면 안전합니다.
- **줄 단위 입력에서 한글을 치면 화면에 빈칸이 남을 수 있습니다.** 셸 스크립트의 `read`처럼 줄 단위로 받는 곳에서 `한글 하나`가 `한 글    하나`처럼 보입니다. 프로그램이 받는 값은 맞습니다. 셸 프롬프트, Claude Code, vim에서는 생기지 않습니다.
- **시험 범위:** Intel 맥의 macOS 15에서 확인했습니다. 한글 입력은 2벌식으로 확인했습니다. Apple Silicon 맥, macOS 11–14, 3벌식은 실기로 확인하지 못했습니다.
- 시험 기록과 남은 문제는 [QA 문서](https://github.com/ReDocu/EQMUX/blob/v0.6.4/docs/qa-0.6.3-macos-usability.md)에 있습니다.
