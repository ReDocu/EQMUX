# 오른쪽 위 메뉴 정리 제안 — 2026-10-15

최종 반영: [update-plan-0.5.0.md](../update-plan-0.5.0.md) §개선 — 오른쪽 위 메뉴 정리 · §결정 14·15·21·22 — 최종본에 맞춰 고쳤다.

기준: `sub_main` 0.4.2 + 미커밋 변경(서버 탭), `docs/archive/mcp-panel-plan-2026-10-15.md`의 MCP 탭.
대상: 앱 바 오른쪽 도구(`AppBar.tsx` `.tools`)와 그 아래 사이드 패널 탭 줄(`SidePanel.tsx` `TABS`).

## 1. 지금

```
오른쪽 위
├─ 앱 바 도구 (6)
│  ├─ 대화 ··········· 사이드 패널 토글 (개요 탭으로 연다)
│  ├─ 임무 ··········· 전체 화면 팝업 [임무 | 탐색기]
│  ├─ 워크스페이스 ···· 전체 화면 팝업 — 탭 줄의 "+"와 같은 동작
│  ├─ 역할 ··········· 전체 화면 팝업
│  ├─ 설정 ··········· 전체 화면 팝업
│  └─ 종료
└─ 사이드 패널 탭 (7 → MCP 추가 시 8) + ◧ ✕
   ├─ 개요 ··········· 대화 스트림 (앱 바 버튼 이름은 "대화")
   ├─ (MCP) ·········· 기획 중
   ├─ git
   ├─ 포트 ··········· 새 포트 배지
   ├─ 서버 ··········· dev 서버용 셸
   ├─ 로그 ··········· 이벤트 스트림 + 스크롤백 검색
   ├─ 브라우저
   └─ MDView ········· 워크스페이스 .md 보기
```

문제:
- 같은 것을 두 이름으로 부른다. 앱 바는 "대화", 탭은 "개요"다.
- 같은 동작이 두 군데 있다. 앱 바의 "워크스페이스"와 탭 줄의 "+"는 둘 다 `toggleOverlay("connect")`를 부른다.
- 사이드 패널 탭이 8개가 되면 ◧ ✕까지 10칸이라 기본 폭에서 줄이 넘칠 가능성이 크다(화면에서 실측은 안 했다).
- 관련 있는 탭이 흩어져 있다(서버·포트, git·MDView).

## 2. 권장

```
오른쪽 위
├─ 앱 바 도구
│  ├─ 대화 ··········· 사이드 패널 토글
│  ├─ 임무 ··········· [임무 | 탐색기]            (그대로)
│  ├─ 역할 ··········· 역할 라이브러리             (그대로)
│  ├─ 설정
│  ├─ 종료
│  ├─ 벨 ············ 알림 센터 (최종본 §주의 고리, 새로)
│  ✗ 워크스페이스 ···· 삭제 — 탭 줄의 "+"가 맡는다
└─ 사이드 패널 탭 (4, 0.5.x에 확장 그룹이 들어와 5) + ◧ ✕
   ├─ 대화 ··········· [대화 | 로그]       ← "개요" 이름 변경, 로그 합침
   ├─ (확장) ········· 0.5.x: [MCP | 플러그인 | 스킬]  (§결정 22)
   ├─ 코드 ··········· [git | 문서]        ← MDView는 "문서"로 이름 변경
   ├─ 실행 ··········· [서버 | 포트]       ← 새 포트 배지는 "실행" 탭에 뜬다
   └─ 브라우저
```

`[a | b]`는 탭 안의 세그먼트다. 임무 팝업의 `[임무 | 탐색기]`와 같은 패턴이라 새 UI 부품이 필요 없다. 세그먼트는 다른 화면으로 바꾸는 데만 쓰고, 목록을 거르는 데는 필터 칩을 쓴다. 새 포트 배지는 "실행" 그룹 탭과 `포트` 세그먼트 양쪽에 붙는다. 0.5로 처음 켰을 때 사이드 패널에 "탭이 묶였습니다" 안내를 한 번만 띄운다.

워크스페이스 탭에는 0.5에서 우클릭 메뉴와 `⋯` 버튼을 새로 둔다(열기·알림·닫기 묶음). 탭 줄 "+"의 툴팁은 "워크스페이스 열기·관리"로 바꾸고, 연결 화면은 열려 있지 않은 워크스페이스를 목록 위에 보인다. 자세한 항목은 최종본 §워크스페이스 탭 메뉴에 있다.

묶은 이유:
- **대화 + 로그**: 둘 다 "에이전트가 무엇을 했나"를 시간순으로 본다. 대화는 메시지, 로그는 이벤트와 스크롤백이다.
- **git + 문서**: 둘 다 저장소 안의 파일을 본다. 임무 팝업의 탐색기는 0.5에 그대로 두고, `[git | 파일 | 문서]`로 옮길지는 0.6에서 본다(§결정 21).
- **서버 + 포트**: 서버 탭에서 연 포트가 포트 패널에 "서버"로 뜬다(`ServerPanelTab.tsx` 머리 주석). 띄우고 확인하는 일이 한 자리에서 끝난다.
- **브라우저**는 따로 둔다. 네이티브 자식 웹뷰라 세그먼트 전환 때 숨김 처리가 따로 필요하다(`BrowserPanelTab.tsx`).
- **MCP**는 플러그인·스킬과 함께 0.5.x에 사이드 패널 "확장" 그룹 하나로 들어온다(§결정 22). 탭을 셋 따로 두면 탭이 다시 7개가 된다.

## 3. 바꾸는 범위

| 파일 | 할 일 |
|---|---|
| `src/components/AppBar.tsx` | "워크스페이스" 도구 버튼 삭제. 같은 줄에 들어오는 벨, 워크스페이스 탭 우클릭 메뉴와 `⋯` 버튼, "+" 툴팁 |
| `src/screens/WorkspaceConnection.tsx` | 열려 있지 않은 워크스페이스를 목록 위로 |
| `src/components/SidePanel.tsx` | `TABS`를 그룹 4개로 바꾼다(0.5.x에 확장 그룹을 더한다). 각 그룹이 하위 키를 가진다. 활성 그룹은 `panelTab()`이 속한 그룹이다. 그룹에 하위 키가 둘 이상이면 세그먼트를 보인다. 포트 배지 조건을 그룹 단위로 옮긴다 |
| `src/state.ts` | 바꾸지 않는다. `PanelTab` 키는 그대로 둔다(0.5.x 확장 그룹 때 `"mcp"` 등을 더한다). `openPanel("git")`, `openPanel("browser")` 같은 호출부 5곳이 그대로 동작한다 |
| `src/i18n/shell.ts` | "코드" · "실행" · "문서" 영어 문구 추가. "개요" → "대화" |

그룹 탭을 누르면 그 그룹에서 마지막으로 본 하위 탭을 연다. 처음이면 첫 하위 탭을 연다.
