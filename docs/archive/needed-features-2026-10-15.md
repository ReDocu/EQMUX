# EQMUX 필요 기능 목록 — 2026-10-15

최종 반영: [update-plan-0.5.0.md](../update-plan-0.5.0.md) §범위 · §주의 고리 · §개선 트랙 · §0.5.x로 넘기는 것 · §0.6 이후로 미루는 것 — 다르게 정한 것은 맨 아래 §최종본 반영 결과에 있다.

기준: `docs/archive/benchmark-comparison-2026-10-15.md`(통합 비교표)와 그 원본 문서들의 "가져올 것" 절. EQMUX `sub_main` 0.4.2와 `docs/update-plan-0.5.0.md`를 대조했다.
고른 기준: EQMUX 원칙을 통과한 것만 넣었다. 원칙은 네 가지다. 자동 실행 경로가 없다. 앱은 키·자격 증명을 쥐지 않는다. `.eqmux/` 파일이 원본이다. 상태를 바꾸는 것은 사람의 버튼이다. 원칙과 충돌하는 기능은 11장에 따로 모았다.

**열 뜻**
- **가진 도구**: 통합 비교표와 원본 문서에서 그 기능을 가진 것으로 확인된 도구.
- **비용**: 기존 코드를 재사용할 수 있는 정도. 작음 · 중간 · 큼.
- **0.5 기획**: `update-plan-0.5.0.md`와의 관계.
  - 기획됨 = 이미 들어 있다.
  - 확장 = 기획된 항목에 작은 조각을 더한다.
  - 신규 = 기획서에 없다.
  - 미룸 = 기획서가 0.6 이후로 미뤘다.

## 1. 한눈에

비교표에서 EQMUX가 비어 있고 다른 도구 다수가 채운 칸은 셋이다: **알림 →이동**, **앱 꺼도 유지**, **모바일·원격**. 원본 문서들은 여기에 **회신 고리**(보낸 쪽이 결과를 받는 장치)를 더했다. 이 목록의 대부분이 이 네 곳을 메운다.

### 1-1. 0.5에 넣거나 당기기를 권하는 것 (기획서와 다른 점)

기획서에 없거나 뒤로 밀려 있지만 작고 원칙과 맞는 것이다. 0.5 기획을 고칠 때 이 표부터 본다.

| ID | 기능 | 기획서 지금 | 권장 | 이유 |
|---|---|---|---|---|
| A1 | 앱 안 알림 센터 + "다음 미확인으로" 단축키 | 0.6으로 미룸 ("알림 플러그인에 클릭 콜백이 없다") | 0.5 | OS 클릭 콜백 없이 앱 안 목록으로 푼다. 비교표에서 →이동이 있는 도구가 8개다 |
| A3 | "나를 기다리는 에이전트" 전역 목록 | P2 (대시보드 주의 카드) | P1 | 데스크톱 분류의 기본기다. 받는 데이터(`waitingFor`)는 이미 있다 |
| B1 | 메시지 전달 결과 돌려주기 | 없음 | 0.5 | BR-01을 고칠 때 같은 자리다. 지금은 항상 "전송됨"이다 |
| B2 | "팀원 메시지는 승인이 아니다" 경계 문장 | 프로젝트 간 메시지에만 | 0.5 | 같은 프로젝트까지 넓힌다. 역할 파일 한 줄이다 |
| B4 | `eqmux send --file` 첨부 | 없음 (결정 8은 "파일에 쓰고 경로를 보내라"는 오류만) | 0.5 | 800자 상한의 출구를 명령으로 만든다 |
| B5 | 인계·보고 형식 규칙 | 없음 | 0.5 | 역할 파일에만 넣는다. 안내문 360자 예산은 그대로다 |
| C1 | 임무 상태 변경 이벤트 기록 | 생성·배정만 (P1) | 0.5 | 같은 P1 작업에 한 경로를 더한다 |
| D6 | 미설치 엔진에 설치 명령 보이기 | 경고 위치만 고침 (P1 U-4·5) | 0.5 | 같은 화면을 고칠 때 붙인다 |
| E1 | 업데이트 때 지우지 말고 `.bak`으로 옮기기 | 결정 1 (b) | 0.5 | (b)에 롤백 길을 더한다 |

### 1-2. 0.5.x에 새로 넣을 것

A5 멈춤·무진행 표시 · B7 `eqmux read`/`list` · D2 저장 명령 · D3 저장소 팀 편성으로 시작 · E4 스크롤백 보안 표기 · F1 한도 표시 + 전달 보류 · G5 브라우저 안전장치

### 1-3. 0.6 첫 안건

- E3 **앱을 꺼도 세션을 살릴지 결정한다.** 비교표에서 데몬·tmux 계열 거의 전부가 ✓다. 다만 Windows 로컬에서는 Emdash도 못 한다.
- E2 **자동 업데이트 + 코드 서명 + 채널.** E1이 먼저 끝나야 한다.

## 12. 지킬 것 — 비교표에서 EQMUX만 가진 칸

새 기능을 넣으면서 이 칸을 흐리지 않는다.

- **타입·원장 ✓ + 역할·권한 ✓ + 자동 실행 ×의 조합.** 타입·원장이 있는 다른 도구(oh-my-claudecode, Gas Town)는 권한 우회나 즉시 실행이 중심이다.
- **Windows 네이티브 + 에이전트 간 메시지 + 메시지 타입.** 앞의 둘을 함께 가진 도구는 Orca, wmux, herdr뿐이고, 타입까지 있는 것은 EQMUX뿐이다.
- **한국어.** herdr와 omc는 한국어 IME 문제를 스스로 문서에 적었다(H4).
