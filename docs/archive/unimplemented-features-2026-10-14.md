## 우선순위 제안

1. 서버 탭 1~3번은 커밋 전에 고친다. 고아 dev 서버와 복구 불가 상태는 바로 드러난다
2. 중지 확인창 3곳 — 되돌릴 수 없는 동작이다
3. Codex 세션 헤더 "에이전트 미기동"과 엔진 표시·변경 — 혼성 팀의 기본 정보다
4. 가짜 저장 버튼과 기본 터미널 구성 화면은 지우거나 실제 동작에 맞춘다
5. 버전 업 때 데이터를 지우는 정책을 유지할지 정하고 문서를 맞춘다
