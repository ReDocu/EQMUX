# EQMUX 0.6 QA 남은 행 수정 결과 (mac 제외)

## 요약

1·2·3차에서 '일부 수정'이나 '수정 안 함'으로 남은 행 중 mac이 필요한 두 행(B269 · U132 템플릿 아이콘)을 빼고 20행을 마저 고쳤습니다. 원장 `제안·기대 동작` 칸 머리를 `[0.6 QA 남은 것 수정 완료 · …]`로 바꿨습니다. 새 릴리스 빌드를 띄워 8행(B208 · B224 · U129 · U151 · P65 · P71 · 앞서 B250 · B254)을 실앱에서 확인했습니다.

| 검증 | 결과 |
|---|---|
| `npx tsc --noEmit` | 오류 0 |
| `npm test` | 42파일 305개 통과 |
| `cargo test --lib` | 251 통과 · 1 무시 · 실패 1 (`ports::tests::attributes_a_port_opened_inside_a_session_job`, 아래) |
| `cargo clippy --lib` | 경고 0 |

`ports` 테스트 실패는 이 PC 환경 때문입니다. `ports.rs`는 HEAD와 같고, 테스트가 띄우는 `node` 리스너(127.0.0.1:47823)가 샌드박스 안팎 모두 `netstat -ano`에 나오지 않습니다(다른 LISTENING 줄은 나옴). 테스트의 전제가 성립하지 않아 코드와 무관하게 실패합니다.

## 실앱 확인

릴리스 빌드(`npx tauri build --no-bundle`)를 시험용 앱 데이터로 띄워 CDP로 조작했습니다. 브라우저 패널의 네이티브 웹뷰가 들어간 화면은 PrintWindow로 창만 찍었습니다. 끝난 뒤 앱 데이터를 백업으로 되돌리고 `diff -rq`로 같은지 확인했습니다.

- **B208** — 셋째 칸의 '+'로 03 슬롯을 만들고 01을 더했다. 03 페인이 그 자리에 살아 있다(`echo alive03` 출력 유지).
- **B224** — 브라우저 패널에 example.com을 연 채로 벨 팝업을 띄우면 웹뷰가 숨는다. 토스트는 웹뷰 반대편(왼쪽 아래)에 보인다.
- **U129** — 연결 화면 제목이 '워크스페이스 연결 · 관리'다.
- **U151** — 배치 창이 8슬롯 · 세션 2개로 그려지고 부제가 바뀌었다.
- **P65** — 세션 2개가 도는 채로 창에 WM_CLOSE를 보냈다. '창을 닫아도 세션 2개가 트레이에서 계속 돕니다' 확인창이 뜨고 [취소]로 남는다.
- **P71** — 세션 0인 워크스페이스도 확인창이 뜬다. [등록 해제] 뒤 토스트 [되돌리기]를 누르면 약 2초 뒤 그 행이 돌아오고 선택된다.

## 관찰 (원장 밖)

- 등록 해제는 확인창이 바로 닫히고 행은 1–2초 뒤에 사라진다. [되돌리기]도 약 2초 걸린다. 그 사이 표시가 없어서, 다시 누르면 맨 위로 옮겨 간 다른 행을 해제할 수 있다(시험 중 실제로 그렇게 됐다). 처리 중 표시나 버튼 잠금을 더하면 좋다.
- [되돌리기] 토스트는 8초 뒤 닫힌다(마우스를 올리면 유지).
