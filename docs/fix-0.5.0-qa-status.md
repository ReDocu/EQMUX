## 남은 것

- **사용자 앱 데이터가 두 번 사라졌다 — 원인 미상.** 21:32에 등록이 14개 → 1개로, 22:31~22:40 사이에 `workspaces.json`·`workspaces/` 폴더가 사라지고 `layout.json`이 빈 열린 목록으로, `data.ver`가 22:35에 다시 쓰였다. EQMUX 코드에는 등록 파일·워크스페이스 폴더를 지우는 경로가 없고(등록 해제는 목록에서만 뺀다), 다른 세션 기록에도 그 폴더를 지운 명령이 없다. 22:35의 앱 실행 흔적이 누구 것인지 찾지 못했다. MobilePuzzleAdless 등록·세션 DB는 22:25 백업에서 되살렸다. 이전 14개는 이전 세션 백업(`5afaab90…/scratchpad/appdata-backup/roaming`)에 있다.
- **P26 한계** — `eqmux`가 아닌 명령과 섞인 복합 명령(예: `$t = Get-Date; eqmux report …`)은 여전히 승인을 묻는다. Codex 세션은 해당 없음.
- **PowerShell 파이프 인코딩** — `eqmux … | Select-Object`처럼 PowerShell 파이프를 거치면 비ASCII 문자(—, 한글)가 깨진다. 파이프 없이 찍을 때는 정상. 이번 범위 밖.
- **남긴 범위** — U59: `eqmux browser` 결과 문구와 세션 시작 역할 컨텍스트는 한국어. B93: 대기 브리프는 앱 메모리에만(재시작 시 사라짐, 임무는 역할 파일에 남음). B92: 0.5.0 이전 배정은 다시 배정해야 시각이 기록된다.
