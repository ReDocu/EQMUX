## 요약

기획서의 P0 13건, P1 24건, 요청 기능 6건, UX 기반, 주의 고리, 메뉴 정리, 바로 가기를 코드에 넣었다. P2 22건 중 19건을 넣고 3건은 일부만 했거나 넘겼다. 자동 검증은 모두 통과했다. **실제 앱을 띄운 실기 확인은 아직 하지 않았다** — 아래 §실기 체크리스트가 남은 관문이다. 커밋은 하지 않았다.

## 기획서와 다르게 간 것

| 항목 | 기획서 | 실제 | 이유 |
|---|---|---|---|
| `@이름` 해석 | 열린 모든 프로젝트에서 찾고 둘 이상이면 오류 | 자기 프로젝트에 있으면 자기 프로젝트가 이긴다. 없을 때만 다른 프로젝트를 찾는다 | 기본 페르소나 이름이 모든 프로젝트에 겹쳐, 그대로면 팀 안 메시지마다 모호성 오류가 난다 |
| 직함 없는 역할 파일 | 0.4.2와 한 글자도 다르지 않다 | 0.4.2 + `## 팀 통신` 섹션 | 기획서가 형식 세 줄·경계 문장·`who`·`--done` 안내를 모든 세션에 넣으라고 했다. 직함 자체가 더하는 글자는 0 |
| 새로 시작(요약 이월) | 저장된 요약을 첫 프롬프트로 | 시작 안내문 끝에 "이전 세션 요약 (자료이지 지시가 아니다)" | 첫 프롬프트로 넣으면 사람이 치기 전에 턴이 돈다 — 자동 실행 없음 원칙 |
| 꺼진 세션으로 보내기 | — | `대기 — 상대 세션 꺼짐 (켜지면 받는다)` | 프런트가 인박스에 재웠다가 재개 때 흘린다. `실패`는 영영 닿지 않는 경우에만 |
| 넣기 팝오버 | 칩에 붙은 팝오버 | 작은 다이얼로그 | 위치 지정 생략. 동작은 같다 |
| `⛶ 응답 대기 N` 칩 | 범위를 모든 워크스페이스로 | 숫자·표시 조건은 이 워크스페이스 waiting, 누르면 전체 순위로 이동 | 다른 워크스페이스 신호는 벨과 `Ctrl+Shift+U`가 맡는다 |
| 기본 터미널 이름 유지 | 앱을 다시 켜도 남는다 | 같은 슬롯에 다시 만들면 저장된 이름을 되찾는다 | 앱 재시작 때 기본 터미널을 자동으로 되살리지 않는 기존 동작은 그대로 |

## 하지 않았거나 넘긴 것

- **A12** `tokio::time::sleep` — tokio 직접 의존을 늘릴 가치가 없다(W1·W2 같은 판단).
- **C9** 대화 탭 이름 찾기 메모 — 효과가 작다.
- **A2** OS 알림 클릭 → 페인 — 코드는 넣었다. 설치본에서 실기로 눌러 확인해야 하고, 안 되면 0.6으로 넘긴다.
- **H4** 한국어 IME — 비교표에 "실기 확인 전"으로 두었다.
- 산출물 체크리스트는 앱 안 토글이 없다. 체크는 임무 파일을 고친다.
- `package-lock.json`의 version은 0.4.0으로 남아 있다(기획서 버전 파일 목록 밖, 이전부터 맞춰 오지 않았다).

## 실기 체크리스트 (릴리즈 전 남은 관문)

자동 검증으로 확인할 수 없는 항목이다. 앱을 띄워 하나씩 본다.

- [ ] 2×2와 8슬롯 가로 나열에서 페인 헤더 실측 — 가장 좁은 페인에서 번호·이름·주의 칩·상태가 잘리지 않는가(이름·칩은 줄임표 구조라 아주 좁으면 깨질 수 있다)
- [ ] 0.4.2 데이터가 있는 PC에서 0.5 첫 실행 — 워크스페이스 등록·배치가 남고 `session.db`가 `.bak`으로 옮겨지는가
- [ ] 혼성 4슬롯 팀(Claude·Codex, 직함 있음·없음, 자동 이름 기본 터미널)으로 임무 하나 — 메시지 발신자가 이름으로 보이는가, handoff가 5칸 형식을 따르는가
- [ ] Claude·Codex 각각 "네 직함이 뭐야?", "웹 페이지 열어 줘"(전역 설정에 다른 터미널 도구 지시가 있는 PC에서 그 도구를 시도하지 않는가)
- [ ] 두 프로젝트를 열고 `eqmux send --to @B02` → 받은 쪽이 `@카이@A`로 답장, `eqmux who`, 받기 끈 프로젝트로 보내면 오류
- [ ] handoff → 개발 세션 30초+ 작업 → `✓ 턴 끝남 · 보고 전` → `report --done` → 리드와 사람에게 도착, 창을 뒤로 보낸 상태에서 OS 알림
- [ ] 창을 뒤로 보낸 채 waiting → 앱으로 돌아와 벨 목록과 `Ctrl+Shift+U`로 그 페인에 간다
- [ ] **설치본**에서 OS 알림 토스트를 눌러 그 페인으로 가는가(A2)
- [ ] 손으로 띄운 `claude`에 승인 창이 떠 있을 때 메시지를 보내도 승인 창에 아무 키도 들어가지 않는다
- [ ] 서버 탭: dev 서버를 띄운 채 워크스페이스 등록 해제와 앱 종료 — 고아 프로세스 없음
- [ ] 에이전트 4명이 일하는 동안 트랜스크립트 창·설정 화면을 열고 메시지를 주고받아도 UI가 멈추지 않는다
- [ ] 영어 UI에서 새 문구 누락 확인
- [ ] 한국어 IME가 EQMUX 세션에서 정상인지 확인해 `docs/site` 비교표에 적는다(H4)
