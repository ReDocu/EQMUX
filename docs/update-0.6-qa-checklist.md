### 브라우저 — eqmux browser (B156 · G5)

| # | 항목 | 절차 | 기대 결과 | 플랫폼 |
|---|---|---|---|---|
| B1 | open 결과 (B156) | 브라우저 패널을 **닫은 채로** `eqmux browser open http://localhost:<포트>` | 첫 줄이 about:blank가 아니라 페이지 제목 · 연 주소. 20초 넘게 걸리면 "여는 중 → <주소>" | 둘 다 |
| B2 | confirm · alert (G5) | `onclick="if(confirm('지울까요?'))document.title='yes'"` 버튼 → snapshot → `click @eN` → 다시 `click @eN --accept` | 첫 click은 바로 돌아오고 "대화상자 — confirm: 지울까요? → 취소", 제목은 그대로. `--accept`면 "→ 확인"이고 제목이 yes. 패널이 멈추지 않는다 | 둘 다 |
| B3 | 사람 손 대화상자 | 같은 버튼을 사람이 패널에서 직접 누른다 | 네이티브 confirm 창이 그대로 뜬다(에이전트 동작 중에만 가로챈다) | 둘 다 |
| B4 | 늦게 뜨는 창 | `setTimeout(()=>alert(1),100)` 버튼을 click → 이어서 snapshot | snapshot이 10초 뒤 "…alert·confirm 창이 떠 있으면 사람이 닫아야 합니다". 사람이 닫으면 다시 된다(알려진 한계) | 둘 다 |
| B5 | console | 패널을 새로 연 뒤 `console.log('hi')` · `console.error` · 잡히지 않은 예외가 있는 페이지 → `eqmux browser console` | 시각 · 레벨과 함께 세 줄이 나온다. 토큰 모양은 가려진다 | 둘 다 |
| B6 | network | 위 페이지에서 `eqmux browser network` | 리소스 줄(종류 · ms · URL). Windows(WebView2)는 상태 코드가 앞에 붙고 mac(WebKit)은 없을 수 있다 | 둘 다 · mac 확인 |
| B7 | 낡은 @eN | SPA(라우터) 페이지 → snapshot → 경로를 바꾸는 링크 click → 옛 `@eN` click | "@eN은 낡은 참조입니다 — snapshot 뒤에 페이지가 바뀌었습니다" · exit 1 | 둘 다 |
| B8 | 자동 승인 | 에이전트 세션에서 `eqmux browser console` · `network` | 승인을 묻지 않는다(W1 eqmux_allow_rules) | 둘 다 |
