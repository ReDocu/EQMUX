## 1. 제품 개요

**하나의 git 저장소를 AI 에이전트 팀이 함께 작업하고, 사람이 그것을 관제하는 Windows 데스크톱 앱.**

EQMUX는 터미널 멀티플렉서(MUX)에 에이전트 팀 관제를 얹은 앱입니다. 워크스페이스(= git repo 1개 = 팀 1개 = 탭 1개)마다 여러 개의 에이전트 세션을 병렬로 띄우고, 관제 대시보드에서 상태를 보고, 임무를 배정하고, 필요할 때 개입합니다.

### 핵심 원칙

| 원칙 | 의미 |
|---|---|
| **관제가 핵심이다** | 대시보드에서 팀 상태(busy / waiting / dead)를 보고, 임무를 배정하고, 개입한다 |
| **터미널이 작업 공간이다** | 실제 일은 각 페인의 에이전트 CLI(Claude Code)가 한다 |
| **앱은 API 키를 보유하지 않는다** | 자체 AI 루프 없이 외부 CLI를 실행할 뿐이다. 인증은 `~/.claude` 소유 |
| **파일이 원본이다** | 팀·역할·임무의 원본은 `.eqmux/` 아래 파일이고, DB는 캐시다. 불일치 시 파일이 이긴다 |
| **자동 실행 경로는 없다** | 상태를 바꾸는 것은 언제나 사용자의 버튼이다. 재시작 후에도 자동 재개 대신 **재개 제안**만 띄운다 |

## 2. 도메인 모델과 용어

```
앱  ─────────────────── 워크스페이스 최대 10개 동시 오픈 (하드 제한)
└─ 워크스페이스 ──────── = git repo 1개 = 팀 1개 = 탭 1개
   ├─ 세션 1~N ───────── = 에이전트 1명 = 터미널 페인 1개 (기본 4, 설정으로 6·8)
   │  └─ 역할 ────────── = 직무(job) + 페르소나(persona)
   └─ 임무 ───────────── = repo 안의 작업 단위 (브랜치 + 목표)
```

- **세션 슬롯 상한** — 기본 4, 설정에서 6·8로 확장 가능(절대 상한 8). 기본값 4는 리소스가 아니라 **가독성** 기준입니다(1920×1080에서 2×2 분할이 에이전트 TUI를 읽을 수 있는 한계). 상한을 줄여도 이미 열린 세션은 닫지 않습니다.
- **페인** — 워크스페이스 탭 안의 화면 분할 단위. **세션 페인**(에이전트/셸 터미널, 슬롯 소비)과 **보조 페인**(에디터·diff·브라우저·트랜스크립트, 슬롯 미소비)의 두 유형뿐입니다.
- **패널** — 사이드 도구 서랍(개요·git·포트·로그·브라우저). 페인이 아니며 분할 그리드 밖에 있습니다.

## 3. 화면 구성

| 표면 | 내용 |
|---|---|
| **탭바** | 맨 왼쪽 **관제 고정 탭** + 워크스페이스 탭(최대 10) + 연결(+) 버튼 |
| **관제 탭** | 대시보드 — 요약 타일 · 워크스페이스 행 · 세션 셀 · 이벤트 피드 · 워크트리 레일 |
| **워크스페이스 탭** | 터미널 페인 그리드 + 좌측 레일(세션·임무·워크트리) + 우측 인스펙터(세션 상세) |
| **사이드 패널** | 개요(대화 스트림) · git · 포트 · 로그 · 브라우저 — 좌/우 도크 전환 가능 |
| **전체 화면 오버레이** | 임무·파일 탐색기 / 워크스페이스 연결 / 역할 라이브러리 / 설정 — 앱 바 전역 도구로 열리고, 동시에 하나만, ESC로 닫힘 |
| **앱 바 전역 도구** | 대화 패널 토글 · 임무 탐색기 · 워크스페이스 연결 · 역할 라이브러리 · 설정 — 터미널 전체 화면에서도 열림 |

창은 작업 표시줄 작업 영역에 맞춰 **최대화 상태로 시작**합니다(복원 크기 1440×900).

## 4. 관제 대시보드

팀 전체를 한눈에 보고 개입하는 고정 탭입니다. 시작 시 기본 포커스(설정으로 변경 가능).

### 상태 모델

세션 상태는 6종입니다 — `starting` / `busy` / `waiting`(대기 대상 표시) / `shell` / `idle` / `dead`.

- 상태는 폴링이 아니라 **실시간 스트림 구독**으로 갱신됩니다. 1차 소스는 Claude Code 세션 레지스트리 감시, 2차 소스는 세션별로 주입되는 훅(턴 시작/종료·알림)입니다.
- **주의 예산 원칙** — 색은 `waiting`·`dead`에만 씁니다. 나머지 상태는 무채색 안에서 구분합니다.
- **관측 저하(degraded)** — 레지스트리 디렉터리에 접근할 수 없으면 살아 있는 세션에 "낮은 신뢰" 뱃지를 붙이고(툴팁으로 사유), 훅 + 프로세스 생존만으로 상태를 유지합니다. 회복되면 자동 해제되며, 전환은 이벤트 피드에 양방향 기록됩니다 — 조용히 열화되지 않습니다.

### 에이전트 감지 배지

세션이 어떤 에이전트 CLI를 실행 중인지 대시보드가 직접 감지합니다. 세션 프로세스 트리를 5초 주기로 스캔해 알려진 에이전트(Claude · Codex · Gemini 등)를 식별하고 세션 셀에 배지로 표시합니다. 사용자가 셸에서 직접 실행한 에이전트도 잡힙니다.

### 알림과 미확인

| 항목 | 동작 |
|---|---|
| OS 알림 | `waiting` · `dead` **진입 2종에만** 발신. 설정에서 waiting만 / 끄기 선택 가능 |
| 억제 | 앱 창 포커스 중에는 억제. 세션당 최소 간격 60초로 합치고 "(N건 합침)" 부기 |
| 의도한 종료 | 사용자가 중지·제거한 세션의 dead는 알림 제외 |
| 사운드 | 기본 꺼짐. 켜면 waiting 진입 전이에 비프 1회 |
| 음소거 | 세션·워크스페이스 단위 음소거 — OS 알림·사운드만 막고 인앱 미확인은 유지 |
| 미확인 | 세션 단위, 알림과 같은 2종에만 마킹. 셀 점 → 탭 점 → 관제 탭 점으로 상위 전파. 페인 점프·상세 열람 시 해제, `모두 확인` 버튼 제공. 재시작 후에도 유지 |

### 대시보드 액션

**점프 · 재개 · 중지**만 제공합니다. 승인·거부·일괄 액션은 의도적으로 없습니다 — 에이전트 TUI 다이얼로그에 키를 주입하는 위험을 피하기 위해서입니다. 중지는 확인 다이얼로그 후 실제 PTY 종료입니다.

### 소프트 경고 배너

- **과부하** — 동시 busy 세션이 임계(잠정 6) 이상이면 상단 배너. 막지는 않습니다.
- **메모리** — 설정 임계값(기본 꺼짐 · 2/4/8GB) 초과 세션을 배너로 나열. 강제 종료·자동 개입은 없습니다.

### 이벤트 피드

이벤트 원장(SQLite `event` 테이블)을 세션 / 워크스페이스 / 전역 3단 스코프로 조회합니다. 세션 상세 패널·컨트롤 센터 스트립·로그 패널이 같은 원천을 씁니다.

## 5. 터미널 워크스페이스

### 페인 배치

- **배치 6종** — 그리드 행/열 · 스택 · 나열 · 메인+우측 · 메인+하단. `Ctrl+Shift+L`로 순환.
- **분할선 드래그** — 그리드 경계 핸들을 끌어 이웃 트랙 비율 조정(트랙 최소 8%), 더블클릭으로 그 축 초기화.
- **줌 / 전체 화면** — 페인 헤더 클릭으로 줌 토글, 전체 화면에서도 내비게이션 유지.
- **레이아웃 영속** — 열린 탭 · 배치 · 분할 비율 · 기본 셸 · 선택 세션 · 패널 도크 방향을 `layout.json`에 저장(800ms 디바운스), 재시작 시 복원.

### 터미널 기능

| 기능 | 동작 |
|---|---|
| PTY | ConPTY — Rust 백엔드가 단독 소유, UI는 IPC로만 접근 |
| 셸 선택 | PowerShell 7 · Windows PowerShell · Git Bash · cmd (드롭다운, 폴백 자동) |
| 터미널 내 검색 | `Ctrl+F` 바 — Enter 다음 / Shift+Enter 이전 / ESC 닫기, 입력 중 증분 검색. 범위는 인메모리 5,000줄(디스크 기록은 로그 패널의 전문 검색 담당) |
| 링크 감지 | URL 클릭 → 기본 브라우저로 (http/https만) |
| 클립보드 | 네이티브 복사/붙여넣기. 이미지 붙여넣기는 PNG로 저장 후 경로 삽입 |
| 드래그 앤 드롭 | 파일을 페인에 떨어뜨리면 경로 삽입 |
| 우클릭 메뉴 | 복사 · 붙여넣기 · 모두 선택 · 검색 · 화면 지우기 |
| 브랜치 배정 | 페인·레일 메뉴에서 셸 터미널을 특정 브랜치의 워크트리로 이동(필요 시 자동 attach) |
| 상태 표시 | 상태 테두리 · 활성 세션 MEM 칩(상태 바) |
| 디스크 페이징 | 링버퍼 최상단에서 "더 이전" 칩 → 저장된 스크롤백을 200줄 단위로 이어서 열람 |

## 6. 에이전트 세션

### 셸 우선(shell-first) 기동

모든 세션은 **일반 셸로 시작**합니다. 팀 캐스팅·편성·역할 부여 어느 경로도 에이전트를 자동 실행하지 않습니다. 에이전트 기동은 언제나 명시적 사용자 액션입니다 — 페인의 재개 카드, 세션 메뉴, 세션 상세 패널.

### Claude Code 실행 방식

- 앱이 발급한 UUID로 `claude --session-id <uuid>` 기동. 권한 모드·도구 차단 플래그를 역할 권한에 맞춰 부여합니다.
- 역할 전달은 환경변수(`EQMUX_SESSION` · `EQMUX_ROLE_FILE` 등)와 `--append-system-prompt` **2줄 포인터**뿐입니다. 사용자의 `CLAUDE.md`, `~/.claude/settings.json`, repo `.claude/`는 수정하지 않습니다.
- 훅은 앱데이터의 설정 파일을 세션별 `--settings`로만 주입합니다. 어떤 실패에도 에이전트 흐름을 막지 않습니다(항상 exit 0).
- PTY 자식 환경은 스폰 시점에 정리됩니다 — TERM/COLORTERM 강제, 상속된 세션 마커 제거(앱 자체가 Claude Code 아래에서 실행돼도 안전).

### 재개와 재시작

- **재개 가능 여부는 실측** — 트랜스크립트 존재를 확인해 판단하고, 앱 재시작 후에는 세션 매핑 테이블로 폴백합니다.
- **재개** — 같은 UUID · 같은 cwd로 `--resume`. 대화가 이어집니다.
- **권한 재시작** — 실행 권한은 프로세스 수명 동안 고정이므로, 권한이 바뀌면 재시작 배지가 뜨고 재개 기반 재시작으로 반영합니다(대화 유지).
- PTY 종료(EOF)는 dead 전이로만 표시하고 **자동 재시작하지 않습니다** — 크래시 루프 방지.

### 계측

- **활동·서브에이전트** — 도구 호출명과 서브에이전트 동시 실행 수를 실측해 세션 상세와 busy 카드에 표시.
- **비용** — statusLine 채널로 세션 누적 비용($)을 수집해 세션 상세에 표시. 에이전트 상태 줄에도 `EQMUX · 모델 · $비용`이 뜹니다.
- **메모리** — Job Object 프로세스 트리의 워킹셋 합산(10초 폴링, 현재값·피크). 표시와 소프트 경고만, 강제 개입 없음.

## 7. 팀 편성 — 직무·페르소나·캐스팅

### 직무(Job) — 고정 8종

직무는 **책임**입니다. 로스터는 8종으로 고정 — **리드**(전권한) · **기획** · **개발** · **디자인** · **QA** · **디버거** · **문서** · **릴리즈**. 추가·복제·삭제는 없고 편집만 가능하며, 빠진 파일은 부팅 시 자동 복원됩니다. push 권한은 리드·릴리즈에만 있습니다. 직무별 배지·색 8종은 단일 원본으로 관리됩니다.

### 페르소나(Persona) — 3단계 레벨

페르소나는 **판단 성향**입니다. 직무와 분리되어 있고, 프롬프트 예산은 5~10줄(초과 시 경고)입니다.

| 레벨 | 내용 |
|---|---|
| **기본** | 판단 힌트만 |
| **중간** | 판단 힌트 + 말투 + 성격 (각 3줄 예산, 말투 프리셋 칩 제공) |
| **고급** | 캐릭터 시트(`personas/<id>.character.md`) 전용 — 역할 파일에는 정체성 1줄 + 경로 포인터만 |

레벨은 frontmatter에 명시 저장되며, 레벨 전환 시 값이 섞이지 않고 하위 레벨로 내려도 디스크의 내용은 보존됩니다. 캐릭터 시트를 저장하면 역할 파일이 재합성되고 캐스팅 중인 세션에 알림이 갑니다. 페르소나에 **기본 직무**를 지정하면 역할 부여 때 직무 선택 없이 따라갑니다.

### 라이브러리

- 원본은 앱데이터의 `jobs/*.md` · `personas/*.md` 파일. 첫 실행 시 페르소나 8종 시드.
- **전역 + 워크스페이스 오버라이드 2단** — 같은 id면 워크스페이스가 이기고, 오버라이드 항목은 WS 뱃지로 구분되며 앱에서는 편집하지 않습니다(파일 경로 안내).
- 페르소나 생성·편집·삭제 완비. 캐스팅 중인 항목은 삭제할 수 없습니다.

### 캐스팅과 프리셋

- **편성 프리셋 4종** (앱데이터 `presets/*.json`, 직무 구성만 정의) — 표준(리드·개발2·QA) / 집중개발 / 제품기획(리드·기획·디자인·개발) / 품질(개발·디버거·QA·문서). 페르소나는 캐스팅 화면이 라이브러리에서 자동 배정합니다.
- 캐스팅 결과는 `.eqmux/roles/<세션>.md`로 합성 저장됩니다 — frontmatter(세션·페르소나·직무·권한·임무)와 본문(성향·책임·금지·팀 관계).
- 슬롯 변경은 `.eqmux/team.json`(원본) + `team.md`(사람·에이전트가 읽는 파생 표)에 500ms 디바운스로 자동 저장됩니다. 둘 다 커밋 대상입니다.
- **세션 이름 분리** — 표시 이름을 페르소나 이름과 별도로 편집할 수 있습니다(비우면 복귀).

### 실행 권한

- 역할 파일 frontmatter의 `permissions`(write / commit / push)가 에이전트 실행 플래그를 결정합니다. 팀 단위가 아니라 **세션 단위**입니다.
- **슬롯 오버라이드** — 세션 상세에서 직무 기본값을 세션 단위로 덮어쓸 수 있습니다(기본값 복귀 버튼 포함). 직무를 바꾸면 이전 오버라이드는 무효화됩니다.
- 비권한 변경은 즉시 반영(파일 갱신 + "다시 읽어라" 한 줄 전달), 권한 변경은 재시작 배지 → 재개 기반 재시작.
- `bypassPermissions`는 어떤 경로로도 제공하지 않습니다.

### 외부 편집 감시

열린 워크스페이스의 `.eqmux/`(임무·직무·페르소나)를 감시해, 에이전트나 외부 도구가 파일을 바꾸면 500ms 디바운스 후 재실측합니다 — **파일이 이깁니다**. 단, 실행 중 세션과 충돌하는 `team.json` 라이브 슬롯 재편은 의도적으로 제외합니다.

## 8. 임무 (Mission)

임무는 repo 안의 작업 단위로, `.eqmux/missions/<슬러그>.md` 파일이 원본입니다(frontmatter + 목표/산출물 섹션).

| 기능 | 동작 |
|---|---|
| 생성·목록 | 임무 탐색기(전체 화면 팝업, 앱 바 버튼)에서 생성·열람. 깨진 파일은 부분 파싱으로 관용 처리 |
| 상태 | 4종 전환 — frontmatter만 갱신, 본문 보존 |
| 배정 | 세션 역할 파일에 임무 블록(마커) 삽입 — 멱등·교체·해제. 배정의 원본은 역할 파일이며 목록 때마다 파일을 직접 스캔합니다 |
| 브리프 | 배정 시 살아 있는 에이전트 세션에 자연어 한 줄 전달 |
| 브랜치 연결 | 임무에 브랜치를 연결하고 `⎇ 체크아웃` 가능(있으면 checkout, 없으면 생성). 공유 repo 전체에 영향이므로 2단 확인 |
| 기본 임무 | ★ 뱃지로 워크스페이스당 1개 지정. 임무 없는 새 역할 세션이 생성 시점에 자동 배정받습니다(done 임무 제외, 생성 시점 외 자동 경로 없음) |

## 9. 대화 — 메시지 버스

에이전트 간 대화는 부가 기능으로, 사이드 패널 **개요 탭**에서 채팅처럼 읽습니다. 진입점은 앱 바 전역 도구라 터미널 전체 화면에서도 열립니다.

- **타입 강제 5종** — `ask` / `handoff` / `report` / `review` / `escalate`. 자유 텍스트는 백엔드가 거부합니다.
- **전달은 상태 기반** — 수신 세션이 idle이면 즉시 PTY 주입, 작업 중(busy·waiting·starting)이면 인박스에 쌓았다가 턴 종료 시 전달. waiting에 즉시 주입하지 않는 것은 TUI 다이얼로그 키 오입력을 피하기 위해서입니다. 대기 현황은 탭 상단에 표시되고, 인박스는 재시작 후에도 유지됩니다.
- **사람도 같은 스트림의 참여자** — `@페르소나이름 내용` 멘션, 생략하면 `@all`(살아 있는 에이전트 전원).
- **발신 상한** — 발신자당 분당 10건 + 본문 2,000자.
- **원장** — 워크스페이스 DB의 message 테이블. 재시작 후에도 스트림이 유지됩니다.
- 에이전트는 터미널에서 `eqmux send`로 같은 스트림에 합류하고, `eqmux report`로 진척을 자기 보고합니다(대화 스트림 + 세션 이벤트 피드 동시 기록).

## 10. 트랜스크립트 뷰

에이전트의 대화 로그를 턴 단위로 열람하는 보조 페인입니다.

- 소스는 Claude Code의 JSONL 로그(`~/.claude/projects/**.jsonl`) **직접 파싱 — 참조만** 하고 복사하지 않습니다. 파일 끝 2MB 창만 로드해 메모리가 파일 크기에 비례하지 않습니다.
- user / agent / tool 턴 구분, 도구 호출은 기본 접힘(펼치면 입력·출력), 로드된 창 안 검색 지원.
- 뷰의 입력창은 PTY로 직행합니다 — 별도 채널이 없습니다.
- 앱이 기동하지 않은(수동 실행) 에이전트는 cwd 기준 최신 JSONL로 추정 폴백하고, 로그를 인식할 수 없으면 스크롤백 폴백으로 자동 전환합니다(TUI 잔재 필터 적용, 전환 사실 표시).
- 세션 스크롤백 저장(내보내기) 버튼을 제공합니다.

## 11. 세션 영속성과 복구

### 저장

| 항목 | 내용 |
|---|---|
| 저장소 3분할 | 파일(팀·역할·임무) / JSON(설정·레이아웃) / SQLite(세션·스크롤백·이벤트·메시지) |
| DB | 워크스페이스별 SQLite(WAL) — 확정된 줄만 100ms 창 / 200행 배치로 적재(전용 쓰기 스레드) |
| 색 보존 | SGR 색 시퀀스를 함께 저장해 재생 시 색 그대로 복원(설정으로 끄면 평문만 — 용량 절감) |
| 전문 검색 | FTS5 인덱스 — 로그 패널에서 Enter로 전 워크스페이스 디스크 검색(FTS5 없는 빌드는 LIKE 폴백) |
| 보존 정책 | 30일 · 세션당 줄 수 상한 · 전역 2GB — 먼저 닿는 것부터 백그라운드 정리 |
| 원문 로그 | 세션별 `~/.eqmux/logs/<세션>.log` append + 폴더 열기 |

### 복구

- **재시작 재생** — 마지막 500줄(설정 500/1k/2k)을 흐리게 재생하고 시각적 경계를 표시합니다.
- **재개 제안** — 복원된 역할 세션 페인은 아무것도 자동 실행하지 않고 `이전 대화 재개 / 새 대화 / 셸` 3택 카드를 띄웁니다. 재개 불가는 사유와 함께 명시합니다.
- **비정상 종료 복구** — 크래시 후 첫 실행에 직전 세션 목록 + 마지막 활동 시각 + 재개 가능 여부 다이얼로그를 띄웁니다. 자동 재실행은 없습니다.
- **웹뷰 크래시 생존** — PTY는 Rust가 소유하므로 렌더러가 죽어도 세션은 계속 삽니다. 웹뷰 자동 리로드 후 생존 세션에 **재부착**해 화면을 복원합니다.

### 수명 관리

- 세션마다 **Job Object**(KILL_ON_JOB_CLOSE)로 자식 프로세스 트리 전체를 묶습니다 — 앱이 죽어도 고아 프로세스가 남지 않습니다.
- **종료 시퀀스** — 창 닫기 = 완전 종료(트레이 상주 없음). 실행 세션이 있으면 확인 다이얼로그(이름·워크스페이스·상태·재개 가능) → 저장 flush → 전 세션 Ctrl+C → 500ms 유예 후 트리 종료.

## 12. 개발 도구 패널

사이드 패널 5탭(개요 · git · 포트 · 로그 · 브라우저)과 보조 페인(diff · 에디터), 전체 화면 팝업(임무·파일 탐색기)으로 구성됩니다. 모든 패널의 스코프는 현재 워크스페이스로 통일됩니다.

### git 패널

- **한 줄 툴바** — 리포 드롭다운(워크스페이스 전환) · 브랜치 팝오버 · ahead/behind · diff / pull / commit / push 버튼.
- **pull · push · commit 버튼은 명령을 클립보드에 복사만 합니다** — 실행은 터미널에서 사람이 합니다(이력 조작 없음 원칙).
- **커밋 목록** — 조밀한 커밋 행(ref 뱃지 · 작성자 · 시각 · 해시 · 그래프 라인). 행 클릭으로 **커밋 diff**(부모 ↔ 커밋)를 diff 에디터에서 열람.
- **브랜치** — 로컬 + 원격 목록, 클릭 체크아웃(공유 repo 고지와 함께 2단 확인), 새 브랜치 생성·전환.
- **워크트리** — 목록 실측(외부 생성 포함, MAIN/세션/외부 뱃지) · 이름 있는 워크트리 생성(base 브랜치 분기) · **기존 로컬 브랜치 attach** · 워크트리에서 셸 열기. **삭제는 제공하지 않습니다** — 머지·정리는 사람 몫.

### diff 뷰어

변경 파일 목록 + 나란히 비교. HEAD↔워크트리와 커밋 diff 모두 지원, 사이드바는 A/M/D/R 상태 문자가 붙은 디렉터리 트리. 신규=전부 추가, 삭제=전부 제거, 바이너리=사유 표시, 3,000줄 상한.

### 파일 탐색기 (전체 화면 팝업)

- 실제 파일 트리(깊이 3 · 400개 상한 · `.git`/`node_modules` 제외) + 폴더 접기/펼치기 + 텍스트 미리보기.
- **파일 CRUD** — 생성 / 이름 변경(같은 부모 안) / 삭제(**휴지통으로**, 2단 확인, 영구 삭제 없음) / 편집 저장. 모든 쓰기에 경로 탈출 가드 + **`.git` 불가침**.
- 임무 파일 변경은 임무 목록 재실측으로 이어집니다.

### 코드 에디터

CodeMirror 6 기반 — 100+ 언어 문법 강조(지연 로드) · 줄 번호 · 검색 · 실행 취소 · `Ctrl+S` 저장. **외부 변경 충돌 감지**(편집 중 에이전트가 같은 파일을 바꾸면 저장 거부) · **미저장 이탈 보호** · 원자적 쓰기 · 전문 읽기 1MB 상한.

### 포트 패널

`netstat` 5초 폴링. 소유 프로세스를 세션 Job Object와 대조해 **세션 포트 / 시스템 포트**를 분리하고, 프로세스명 실측 · 충돌 · 외부 노출을 집계합니다.

### 로그 패널

이벤트 원장 실시간 스트림 + 전문 검색(Enter = 전 워크스페이스 디스크 검색). 검색 히트의 전후 문맥을 스크롤백 페이징으로 열람할 수 있습니다.

### 브라우저 패널

세션이 띄운 로컬 서버 미리보기. 실측 포트 칩 + 주소 입력 → iframe 렌더 + 새로고침. **대상은 localhost·127.0.0.1 전용** — 외부 URL은 사용자의 기본 브라우저로 보냅니다.

## 13. git 워크트리 격리

- 기본은 repo 루트 공유. 역할 세션 생성 시 체크박스로 **세션별 워크트리 격리**를 옵트인하면 `.eqmux/worktrees/<세션>` + 전용 브랜치 `eqmux/<세션>`가 만들어집니다(멱등).
- `team.json`에는 경로가 아니라 플래그만 기록됩니다(커밋 대상이므로 절대 경로 금지). 복원 시 이 머신에 실재하면 그 cwd로, 없으면 repo 루트로 폴백합니다.
- 관제 좌측 레일에 **워크트리 섹션** — 트리별 브랜치 · MAIN/세션/외부 태그 · 그 트리에서 실행 중인 세션(상태 점, 클릭 점프) · 셸 열기 · 생성 팝오버(새 브랜치 / 기존 브랜치 attach).
- 세션 제거 시 워크트리는 보존됩니다. `.eqmux/.gitignore`에 `roles/` · `worktrees/`가 자동 추가됩니다.

## 14. 외부 인터페이스 — eqmux CLI

설치된 단일 바이너리(`eqmux.exe`)가 곧 CLI입니다. 에이전트·셸 PTY의 PATH 앞에 앱 폴더가 붙어 어디서든 `eqmux`로 실행됩니다. 운반로는 Windows 명명 파이프(같은 OS 사용자 스코프)입니다.

| 명령 | 용도 |
|---|---|
| `eqmux send --type <ask·handoff·report·review·escalate> [--to @이름] "내용"` | 에이전트 발신 — 사람 발신과 같은 원장 경로·검증·상한 공유 |
| `eqmux report "한 줄"` | 진척 자기 보고 — 대화 스트림 + 세션 이벤트 피드 동시 기록 |
| `eqmux ping` | 연결 확인 |
| `eqmux _hook <Event>` | Claude Code 훅 진입점(앱이 주입) — 어떤 실패에도 exit 0 |
| `eqmux _statusline` | statusLine 채널(앱이 주입) — 비용 수집 + 상태 줄 출력 |

에이전트에게는 시스템 프롬프트 포인터 한 줄로 이 표면을 알려줍니다.

## 15. 설정

앱데이터 `settings.json`에 원자적으로 저장되며 즉시 동작에 연결됩니다.

| 설정 | 옵션 (기본값 굵게) |
|---|---|
| 시작 화면 | **관제** / 마지막 워크스페이스 |
| OS 알림 라우팅 | **waiting·dead** / waiting만 / 끄기 (꺼도 인앱 미확인 유지) |
| waiting 사운드 | 켜기 / **끄기** |
| 스크롤백 재생 줄 수 | **500** / 1,000 / 2,000 |
| 음소거 목록 | 세션·워크스페이스 id 배열 |
| 테마 | **다크** / 라이트 / 시스템 — 터미널 페인은 어느 테마든 다크(ANSI 가독성) |
| 메모리 배너 임계값 | **꺼짐** / 2 / 4 / 8 GB |
| SGR 색 저장 | **켜기** / 끄기(용량 절감) |
| 세션 슬롯 상한 | **4** / 6 / 8 — 줄여도 열린 세션은 닫지 않음 |
| UI 언어 | **한국어** / English |

보존 상한·권한 정책 같은 고정 정책은 화면에 선언만 하고 설정으로 바꿀 수 없습니다.

### 다국어(i18n)

UI는 한국어(기본)·영어를 지원합니다. 코드의 한국어 원문이 곧 번역 키이고, 영어 모드에서만 사전 치환하며, 미번역 키는 한국어로 폴백합니다. **데이터는 번역하지 않습니다** — 이벤트 원장, 페르소나·직무 파일 내용, 터미널 출력, git 결과는 원문 그대로입니다.

## 16. 단축키

| 키 | 동작 |
|---|---|
| `Ctrl+Shift+D` | 관제 탭 토글 (다시 누르면 직전 워크스페이스 탭) |
| `Ctrl+Shift+L` | 페인 배치 순환 |
| `Ctrl+F` | 터미널 내 검색 (Enter 다음 / Shift+Enter 이전 / ESC 닫기) |
| `Ctrl+S` | 에디터 저장 |
| `ESC` | 전체 화면 팝업·오버레이 닫기 |

## 17. 파일 계약

### 워크스페이스 `.eqmux/`

| 파일 | 역할 | 커밋 |
|---|---|---|
| `team.json` | 팀 편성 원본 | ✅ |
| `team.md` | 에이전트가 읽는 파생 표 | ✅ |
| `roles/<세션>.md` | 세션별 역할 합성 결과 — frontmatter `permissions`가 실행 플래그 결정 | gitignore |
| `missions/*.md` | 임무 정의 (브랜치 + 목표) | ✅ |
| `worktrees/<이름>/` | 워크트리 (세션 격리 옵트인 · 이름 있는 트리) | gitignore |

### 앱 데이터 (사용자 프로필)

| 위치 | 내용 |
|---|---|
| `jobs/*.md` · `personas/*.md` (+ `*.character.md`) | 직무·페르소나 라이브러리 (전역) |
| `presets/*.json` | 편성 프리셋 |
| `settings.json` · `layout.json` | 설정 · 레이아웃 |
| `workspaces/<id>/session.db` | 워크스페이스별 SQLite (스크롤백·이벤트·메시지) |
| `~/.eqmux/logs/<세션>.log` | 세션 원문 로그 |

## 18. 설계상 하지 않는 것

이 항목들은 미구현이 아니라 **의도된 경계**입니다.

- **API 키 미보유** — 자체 AI 루프 없음. 인증은 `~/.claude` 소유, 머신 단위 단일 계정.
- **자동 실행 경로 없음** — 자동 재개·자동 재시작·자동 개입 없음. 재개는 언제나 제안 카드.
- **`bypassPermissions` 미제공** — 권한 체계를 무의미하게 만들기 때문.
- **git 이력 조작 없음** — pull · push · commit · 스테이지는 앱이 실행하지 않습니다(버튼은 명령 복사만). 워크트리 삭제도 없습니다.
- **프로세스 조작 없음** — 포트 패널에서 프로세스 kill 제공 안 함.
- **승인·거부 대행 없음** — 에이전트 TUI 다이얼로그에 키를 주입하지 않습니다.
- **임의 웹 브라우징 없음** — 브라우저 패널은 localhost 전용, 외부 URL은 사용자의 브라우저로.
- **트레이 상주 없음** — 창 닫기 = 완전 종료.
- **사용자 설정 불가침** — `CLAUDE.md` · `~/.claude/settings.json` · repo `.claude/`를 수정하지 않습니다.
